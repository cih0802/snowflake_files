### ▣ O269-C-5 ERP `YEAR` 비숫자(115행 · 「지출」) 처방 비교

| 안 | 방법 | 장점 | 위험 |
|---|---|---|---|
| ㉮ | 원천 정정(사용자 안) | 데이터·금액 보존 · 모델 무변경 | 원천 담당 일정 의존 |
| ㉯ | 모델 필터 `TRY_TO_NUMBER(YEAR) IS NOT NULL` | 즉시 복구 | 🔴 115행이 **조용히 빠진다**(금액 손실 · `R2-7` 축) |
| ㉰ | ㉯ + 격리 모델(불량 행 보관) + dbt test `warn`(건수 > 0) + 알림 | 파이프라인 정지 없음 · 손실이 **보인다** | 모델 1·테스트 1 추가 |
| ㉱ | 다른 컬럼에서 연도 유도 · 밀린 컬럼 재배치 | 행 보존 | 🔴 근거 없는 보정 = 값 창작 · 금지 권장 |

- 권장 = **㉮ + ㉰ 병행**(정정 전까지 ㉰ 로 파이프라인 유지 · 정정 후 경고 0 확인).
- 🔴 「지출」이 `INCOME_EXPS_DIV_NM` 값이라면 **행 전체가 한 칸 밀린 것**이다 ⇒ `gn_erp_not_total` 필터와 금액 컬럼도 틀렸다 · 형제 모델 `ERP_BUDGET`(월) · `ERP_BUDGET_ITEM` 도 같은 원천이라 함께 본다(R95 Q08·Q09 로 판정).
