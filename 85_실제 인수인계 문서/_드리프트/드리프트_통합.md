# 드리프트 통합

작업계획서 §1-4: 문서와 라이브가 다르면 라이브를 따르고 차이를 여기 적는다. 원본(80번 패키지)은 고치지 않는다.

- 유형: `미배포`(설계에 있고 라이브에 없음) · `낡은 기재`(문서가 현 상태와 다름) · `설계 모순`(설계끼리 충돌) · `데이터 차이`.
- 축: `[공통]` = 계정과 무관한 문서·설계 문제 · `[ENV]` = 계정마다 다시 판정.
