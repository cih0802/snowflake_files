# D13. 설계 의사결정 기록 · 이슈 대장

본문 = `D13_의사결정대장.csv`(DEC 48행 · ID · 상태 · 결정일 · 제목 · 정본 좌표). 미결 이슈는 A8 이 정본이다.

## 1. [공통] 설계 의사결정 (DEC)

### 1-1. 규모

| 항목 | 값 | 근거 |
|---|---|---|
| 정본 조각에 등장하는 DEC ID | 59종(DEC-1 ~ DEC-62 · 5·6·7 결번) | 조각 전수 정규식 |
| 그중 **제목으로 정의된 것**(대장 수록) | 48행 = 번호 44종 + 하위 번호 4(`14-A` · `17-A` · `17-B` · `17-C`) | `d13_dec_extract.py` |
| 상태 — 결정 | 35 | 제목 선두 ✅·🟢 |
| 상태 — 결정 대기 | 2 — `DEC-46`(명명 규약 전 계층 확장) · `DEC-58`(요청 grain 차원 · 결연활동 팩트 신설) | 제목 선두 🟠 |
| 상태 — 부분 종결 | 1 — `DEC-42`(FACT_BUDGET 추경·조정 예산 슬롯) | 🟡 |
| 상태 — 표기 없음 | 10 — 상위 절의 하위 결정(`DEC-14`~`DEC-17-C` 등) · 범위 제목(`DEC-8`) | 상위 절 상태를 따른다 |
| 다음 발급 번호 | `DEC63` | `id_collision_gate --next DEC` |

- 🔴 대장에 없는 15종(`DEC-1~4` · `9~13` · `18` · `20` · `22` · `32` · `34` · `36`)은 **표 행이나 범위 제목**(「DEC-8 ~ DEC-11」 · 「DEC-19 ~ DEC-22」) 안에서 정의됐다 ⇒ 정본은 `-001`(1~4·9~13·18·20·22)·`-008`(32·34·36) 조각이다. 이 대장은 그 행을 옮겨 적지 않았다.
- 🔴 이 대장은 **색인**이다. 결정 내용을 인용할 때는 좌표 열의 조각을 읽는다.

### 1-2. 운영·유지보수에 직접 영향을 주는 결정

| DEC | 내용(제목 요지) | 운영 영향 |
|---|---|---|
| DEC-25 · DEC-46 | 컬럼 명명 = 코드는 원천명 · 라벨은 분석용어 · 전 계층 확장(🟠 대기) | 컬럼 추가 시 따를 규칙(A4) |
| DEC-37 · DEC-38 · DEC-48 · DEC-50 | SILVER 계층 내 파생 경계 · 명명 이원화 · GA 계열 `BIGQUERY_*` 전환 | 모델 신설 시 이름 규칙 |
| DEC-40 · DEC-41 | GA 사용자 ID 결측 행 미편입 · 다중 후원사업 월 처리 | 수치 해석(D12) |
| DEC-44 | 예산 편성 차수 — 연도별 최신 차수만 | 예산 SV 수치(DR-29 와 별건) |
| DEC-49 · DEC-52 | COMMENT 경량화 · 4블록 템플릿 | COMMENT 작성 규칙(N07 템플릿) |
| DEC-53 | 마스터 이력 = Stream 전면대체·RAW_HIST 기각 | 이력 설계 |
| DEC-56 | 조직 축 = 실적부서 전체 유지 · 본부/지부 = 부서코드 접두 | 조직별 집계 |
| DEC-61 | 스냅샷 영구 미가동 | 일배치에 snapshot 단계를 넣지 않는다(A6 §5) |
| DEC-62 | 코호트 획득 사건 = 신규 우선 → 최초 개발 | 코호트 수치 |
