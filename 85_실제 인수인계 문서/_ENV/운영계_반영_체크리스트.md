# 운영계 반영 체크리스트

> 🆕 **[2026-10-27] 재측정 = `운영계_재측정_20261027.md`** — ② 15종 + R 계열 6종을 한 번에 다시 잰다(운영계 = 측정만 · ③·④ = 개발계). 아래 절차는 최초 반영(O247) 기준이다.

> 🔴 **순서 = ① 준비 → ⑤ 적용 → ② 캡처 → ③ 생성기 → ④ 운영계 열 → ⑥ 끝내기.** (재측정은 적용이 끝난 뒤 한다)
