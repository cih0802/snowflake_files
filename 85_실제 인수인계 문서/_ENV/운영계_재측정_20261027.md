# 85번 운영계 재측정 키트 (2026-10-27)

## 0. 역할 분담

| 어디서 | 누가 | 무엇을 |
|---|---|---|
| 운영계 ZL50263 | 실행 담당 LLM 또는 사람 | §1의 명령을 실행하고 **결과 폴더를 그대로** 돌려준다 |
| 개발계 UM80684 | 문서 작성 담당 | §3 생성기 4종 · 운영계 열 채우기 · 서술 갱신(체크리스트 ③·④) |

- 문서는 고치지 않는다. 85번 원칙 = 「문서는 그대로, 계정 값만 다시 잰다」.
- 21개 SQL 파일은 개발계에서 읽기 전용 검사를 미리 통과시켰다(문장 225개 · 전부 SELECT/WITH/SHOW/DESC).

## 1. 운영계 실행 — 🔴 실행자 지시 (이 절만 읽고 그대로 따른다)

```text
[실행자 지시]
1. 계정이 ZL50263 인지 먼저 확인한다:  SELECT CURRENT_ACCOUNT();
   - ZL50263 이 아니면 아무것도 실행하지 말고 「계정 불일치: <값>」만 보고하고 멈춘다.
2. 롤 = ACCOUNTADMIN (ACCOUNT_USAGE · SHOW 를 읽는다). WH = GN_DW_ANALYTICS_WH 권장.
3. dbt "daily" build(06:01 KST)가 끝난 뒤에 실행한다. 진행 중이면 끝날 때까지 기다린다.
4. §1-1 의 21줄을 워크스페이스 루트에서 위에서부터 순서대로, 문구 그대로 실행한다. 명령을 고치지 않는다.
5. 한 줄이 실패해도 다음 줄로 넘어간다. 고치려 하지 않는다. 각 줄의 마지막 출력 1줄만 그대로 적는다.
6. 파일을 손으로 고치거나 지우지 않는다. SQL 파일을 편집하지 않는다. 다른 SQL 을 실행하지 않는다.
7. 생성기(a2_matrix_build · b_struct_build · n03_catalog_build · n05_report_build)는 실행하지 않는다.
8. 끝나면 §1-2 의 「돌려줄 것」만 돌려준다. 결과를 요약·해석·판정하지 않는다.
```
