## 5. S3 — dbt 배포본 갱신 + build (👤 사람 · 에이전트는 실행하지 않는다 `R4-1`)

```sql
-- ① 배포본 갱신 (O202-C 교훈: EXECUTE 는 배포본을 돈다 · 워크스페이스 수정이 자동 반영되지 않는다)

```

- 범위를 줄이려면 개발계가 쓴 선택자를 쓴다(O202-A·B·C):
  `ARGS = 'build --select DIM_SPONSORSHIP+ FACT_MEMBER_EVENT+ CRM_PAYMENT_BILLING+ CRM_EVENT_PARTICIPATION+ FACT_MESSAGE_DISPATCH+'`
  🔴 그러나 GOLD 전 모델 파일이 이 기간에 바뀌었으므로 **전체 build 를 권한다**.
- 🟠 `FACT_BIGQUERY_BEHAVIOR` 는 롤링 창이다. 운영계에서 이 테이블이 이미 정상(행 > 0)이면 백필하지 않는다.
  0행이면 파일을 고치지 말고 ARGS 로 백필한다(`dbt_project.yml` 106~108행 주석):
  `ARGS = 'build --select FACT_BIGQUERY_BEHAVIOR+ --vars ''{"bigquery_lookback_days": 999}'''`

build 후 확인:

```sql
SELECT COUNT(*) FROM GN_DW.GOLD.FACT_MEMBER_MONTHLY WHERE MONTH_KEY > 210000;   -- 0 (미래월 필터)
SELECT COUNT(*) FROM GN_DW.GOLD.FACT_MEMBER_MONTHLY WHERE STOP_AMT_CNT > 0;     -- > 0
SELECT COUNT(*) FROM GN_DW.GOLD.FACT_BIGQUERY_BEHAVIOR;                         -- > 0
```
