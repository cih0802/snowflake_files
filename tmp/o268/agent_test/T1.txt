질문: 알림톡 템플릿 AT006040 을 받은 회원 중 수신 후 5일 이내에 그 템플릿 링크를 클릭한 회원 수를 알려줘.
도구: ['analyst_service', 'system_execute_sql'] · SV ['GN_DW.SERVING.SV_SERVICE'] · 표 0 · 오류 []

**① 핵심 요약**
- 알림톡 템플릿 AT006040을 받은 회원 중 수신 후 5일 안에 그 템플릿 링크를 클릭한 회원은 **9명**입니다(GN_DW 기준).
- 클릭은 모두 2025-09-17 하루에 있었습니다.

**▼ 상세**
- **세는 방법:** 템플릿 ID가 AT006040인 알림톡을 받은 회원만 셌습니다. 그중 그 템플릿 링크와 일치하는 클릭만 넣었습니다. 기간은 수신 당일부터 5일 뒤(D+0 - D+5)까지입니다. 한 회원이 여러 번 클릭해도 1명으로 셌습니다.
- **'클릭'의 기준:** 원천에는 알림톡 오픈 기록이 없습니다. 그래서 카카오 경로로 홈페이지에 들어온 기록(GA 링크 클릭)을 클릭으로 봤습니다. GA 기록이 연결되지 않은 회원은 실제로 클릭했어도 이 숫자에 들어가지 않습니다.
- **수신 회원 수는 빠져 있습니다:** 이번 조회는 클릭 기록에서 템플릿 ID로 찾은 것이라, 전체 수신 회원 수(분모)는 함께 나오지 않았습니다. 클릭 비율이 필요하시면 수신 회원 수를 따로 조회하겠습니다.
- **함께 볼 수 있는 숫자:** 이 템플릿을 받은 뒤 5일 안에 어떤 알림톡이든 열어 본 회원 수도 낼 수 있습니다. 다만 이 9명과는 기준이 다르므로 합치지 않고 따로 보여 드립니다.
- **원천:** CRM(UMS 발송) → BRONZE_CRM.TM_MS_MSG_AT_SNDNG·TD_MS_MSG_AT_SNDNG_DTLS → GOLD.FACT_MESSAGE_DISPATCH. 클릭 기록은 GOLD.FACT_AT_GA_CLICK입니다.

--- SQL ---
WITH __atclk AS (
  SELECT
    date_sk,
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT __atclk.member_dk) AS "템플릿 링크 클릭 회원수(명)",
  MIN(__date.full_date) AS "최초 수신일",
  MAX(__date.full_date) AS "최종 수신일"
FROM __atclk
LEFT JOIN __date
  ON __atclk.date_sk = __date.date_sk
WHERE
  __atclk.template_id = 'AT006040'
  AND __atclk.map_matched = 1
  AND __atclk.days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
WITH __atclk AS (
  SELECT
    days_from_send AS click_days_from_send,
    map_matched AS click_map_matched,
    template_id AS click_template_id,
    date_sk,
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT __atclk.member_dk) AS "템플릿 링크 클릭 회원수(명)",
  MIN(__date.full_date) AS "최초 클릭 기준일",
  MAX(__date.full_date) AS "최종 클릭 기준일"
FROM __atclk
LEFT JOIN __date
  ON __atclk.date_sk = __date.date_sk
WHERE
  __atclk.click_template_id = 'AT006040'
  AND __atclk.click_map_matched = 1
  AND __atclk.click_days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
