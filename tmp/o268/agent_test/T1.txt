질문: 알림톡 템플릿 AT006040 을 받은 회원 중 수신 후 5일 이내에 그 템플릿 링크를 클릭한 회원 수를 알려줘.

**① 핵심 요약**
- 알림톡 템플릿 AT006040을 받은 회원 가운데 받은 날부터 5일 안에 그 템플릿 링크를 누른 회원은 **14명**입니다(GN_DW 기준).
- 이 템플릿은 **2025-09-17**에 한 번 발송됐습니다. 14명이 남긴 클릭 기록은 모두 201건입니다.

**▼ 상세**
- **세는 방식:** 알림톡은 원천에 '열어 봤다'는 기록이 없습니다. 그래서 받은 날(0일)부터 5일째까지 카카오 경로로 홈페이지에 들어와(GA 기록) 템플릿 AT006040의 링크를 누른 경우를 '클릭'으로 봤습니다. 회원번호 기준으로 중복 없이 셌습니다.
- **명과 건의 차이:** 회원 수는 14명이고 201건은 클릭 기록 수입니다. 한 회원이 여러 번 누르면 기록이 그만큼 늘어나므로, 회원 수로 볼 때는 14명을 쓰시면 됩니다.
- **알 수 없는 것:** 이 템플릿을 받은 전체 회원 수(분모)는 이번에 조회하지 않았습니다. 클릭 기록은 템플릿 ID로 바로 거를 수 있지만, 발송 기록은 템플릿 ID로 거를 수 없기 때문입니다. 그래서 클릭한 비율(%)은 계산하지 않았습니다. 필요하시면 발송 제목으로 이 알림톡 수신 회원을 찾아 비율을 함께 내겠습니다.
- 클릭한 회원이 30명이 안 되므로, 이 결과만으로 클릭한 회원의 특성을 일반화하기는 어렵습니다.
- 원천: CRM(UMS) → BRONZE_CRM.TM_MS_MSG_AT_SNDNG·TD_MS_MSG_AT_SNDNG_DTLS + GA 홈페이지 유입 기록 → GOLD.FACT_AT_GA_CLICK

--- SQL ---
WITH __atclk AS (
  SELECT
    days_from_send AS click_days_from_send,
    template_id AS click_template_id,
    date_sk,
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT a.member_dk) AS "링크 클릭 회원수(명)",
  COUNT(*) AS "클릭 기록(건)",
  MIN(d.full_date) AS "최초 수신일",
  MAX(d.full_date) AS "최종 수신일"
FROM __atclk AS a
LEFT JOIN __date AS d
  ON a.date_sk = d.date_sk
WHERE
  a.click_template_id = 'AT006040'
  AND a.click_days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
