질문: 알림톡 링크 https://www.gni.kr/?utm_campaign=25acpi_om_gift 를 클릭한 회원 수를 수신 후 5일 이내 기준으로 알려줘.
도구: ['analyst_service', 'system_execute_sql'] · SV ['GN_DW.SERVING.SV_SERVICE'] · 표 0 · 오류 []

**① 핵심 요약**
- GN_DW 기준으로, 알림톡을 받고 5일 안에(수신일~D+5) 링크(utm_campaign = 25acpi_om_gift)를 누른 회원은 **12명**입니다.
- 이 12명이 누른 횟수는 모두 **80건**입니다. 해당 수신일은 2025-09-17 - 2026-06-17 사이입니다.

**② 그래프**
- 값이 하나뿐이라 그래프는 그리지 않았습니다.

**③ ▼ 상세**
- **세는 방식:** 알림톡 수신 뒤 카카오 경로로 홈페이지에 들어온 GA 클릭 가운데, 클릭 URL의 utm_campaign 값이 `25acpi_om_gift`인 것만 셌습니다. 수신 당일(D+0)부터 D+5까지의 클릭이며, 회원은 중복 없이 한 명으로 셌습니다.
- **열람 판단 기준:** 원천 데이터에 알림톡을 열어 본 기록이 없습니다. 그래서 링크(GA) 클릭을 열람으로 대신 판단했습니다.
- **해당 템플릿:** 이 링크가 들어간 알림톡 템플릿은 4종입니다. 여러 번 보낸 발송분을 모두 합친 값입니다.
- **수치 해석:** 클릭 건수(80건)에는 한 회원이 여러 번 누른 클릭이 모두 들어 있습니다. 회원 수는 12명으로 읽어 주십시오.
- **표본 수:** 클릭한 회원이 12명(30명 미만)이라 이 회원들의 특성을 일반화하기는 어렵습니다.
- **원천:** CRM(UMS 발송) → BRONZE_CRM.TM_MS_MSG_AT_SNDNG·TD_MS_MSG_AT_SNDNG_DTLS → GOLD.FACT_MESSAGE_DISPATCH. 여기에 GA 클릭 데이터를 연결해 GOLD.FACT_AT_GA_CLICK에서 셌습니다.
- **더 볼 수 있는 내용:** 템플릿별·수신 월별로 나눈 클릭 회원 수, 클릭 회원 가운데 5일 안에 중단하거나 증액한 회원 수를 따로 볼 수 있습니다.

--- SQL ---
WITH __atclk AS (
  SELECT
    date_sk,
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT a.member_dk) AS "링크 클릭 회원수(명)",
  COUNT(*) AS "클릭(건)",
  MIN(d.full_date) AS "최초 수신일",
  MAX(d.full_date) AS "최종 수신일",
  COUNT(DISTINCT a.template_id) AS "템플릿 수",
  COUNT(DISTINCT a.landing_path) AS "랜딩 경로 수"
FROM __atclk AS a
LEFT JOIN __date AS d
  ON a.date_sk = d.date_sk
WHERE
  a.utm_campaign = '25acpi_om_gift'
  AND a.days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
WITH __atclk AS (
  SELECT
    days_from_send AS click_days_from_send,
    template_id AS click_template_id,
    utm_campaign AS click_utm_campaign,
    date_sk,
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT a.member_dk) AS "링크 클릭 회원수(명)",
  COUNT(*) AS "클릭(건)",
  MIN(d.full_date) AS "최초 수신일",
  MAX(d.full_date) AS "최종 수신일",
  COUNT(DISTINCT a.click_template_id) AS "템플릿 수"
FROM __atclk AS a
LEFT JOIN __date AS d
  ON a.date_sk = d.date_sk
WHERE
  a.click_utm_campaign = '25acpi_om_gift'
  AND a.click_days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
