- 표는 광고비가 큰 순서로 정렬했습니다. 표 끝의 전체·시작연월·종료연월 열은 참고용 값이며, 마케팅캠페인 행마다 같은 값이 들어 있습니다.
- 조회 기간은 2026년 1월 - 2026년 10월입니다. 데이터가 2026년 10월까지 적재돼 있어 그 이후는 들어 있지 않습니다.
- (미매핑)은 마케팅캠페인 마스터에 연결되지 않은 건입니다. 표에서 빼지 않았으므로 캠페인별 값에 (미매핑)을 더하면 같은 기간 전체와 같습니다. 이 금액의 대부분은 재방송·영상 광고비입니다. 방송명·프로그램별로 나눠 보는 것은 광고 실적 도구로 따로 볼 수 있습니다.
- 개발(건)은 MSTR 기준입니다. 후원금액 ÷ 10,000으로 계산하며 신규·증액·재후원을 합친 값입니다. 그래서 소수가 있습니다.
- 개발단가는 광고비 ÷ MSTR 개발(건)입니다. 대행사 리포트 기준 개발단가와는 분모가 달라 서로 다른 지표입니다. 개발(건)이 없는 캠페인은 개발단가를 비워 두었습니다.
- 제작비 세세목 정의가 아직 없어서, 세부캠페인코드가 적힌 지출결의 전체를 제작비로 잡았습니다. 실제 제작비와 다를 수 있고, 코드를 적지 않은 지출은 빠져 있습니다.
- 디지털 최종정산금액은 광고비에 마크업과 부가세를 더한 금액이며 디지털 광고에만 있습니다. 영상·재방송만 집행한 캠페인은 이 칸이 비어 있습니다.
- 광고비 0원은 금액이 실제로 0으로 기록된 경우이고, 빈칸은 해당 비용이나 개발 실적이 없는 경우입니다.
- 「위기가정(함께한끼)」는 개발이 12건뿐이라 개발단가가 41,345,131.67원으로 아주 높습니다. 개발 실적이 다른 캠페인(예: 국내결식(함께한끼) 4,746.5건)으로 잡혔을 수 있으니 해석할 때 주의해야 합니다.

WITH __mcc AS (
  SELECT
    month_key,
    mktg_campaign_sk,
    prod_cost,
    dev_cnt_mstr,
    ad_cost,
    last_stmt_amt
  FROM GN_DW.GOLD.FACT_MKTG_CAMPAIGN_MONTHLY_COST
), __mktg AS (
  SELECT
    mktg_campaign_sk
  FROM GN_DW.GOLD.DIM_MARKETING_CAMPAIGN
)
SELECT
  mc AS "마케팅캠페인명",
  ad AS "광고비(원)",
  settle AS "디지털 최종정산금액(원)",
  prod AS "제작비(원)",
  dev AS "개발(건)",
  CAST(ROUND(unit, 2) AS DECIMAL(38, 2)) AS "개발단가(원)",
  tot_ad AS "전체 광고비(원)",
  tot_prod AS "전체 제작비(원)",
  tot_dev AS "전체 개발(건)",
  min_m AS "시작연월",
  max_m AS "종료연월"
FROM (
  SELECT
    COALESCE(__mktg.mktg_campaign_name, '(미매핑)') AS mc,
    SUM(__mcc.ad_cost) AS ad,
    SUM(__mcc.last_stmt_amt) AS settle,
    SUM(__mcc.prod_cost) AS prod,
    SUM(__mcc.dev_cnt_mstr) AS dev,
    SUM(__mcc.ad_cost) / NULLIF(NULLIF(SUM(__mcc.dev_cnt_mstr), 0), 0) AS unit,
    SUM(SUM(__mcc.ad_cost)) OVER () AS tot_ad,
    SUM(SUM(__mcc.prod_cost)) OVER () AS tot_prod,
    SUM(SUM(__mcc.dev_cnt_mstr)) OVER () AS tot_dev,
    MIN(MIN(__mcc.month_key)) OVER () AS min_m,
    MAX(MAX(__mcc.month_key)) OVER () AS max_m
  FROM __mcc
  LEFT JOIN __mktg
    ON __mcc.mktg_campaign_sk = __mktg.mktg_campaign_sk
  WHERE
    __mcc.month_key BETWEEN 202601 AND 202612
  GROUP BY
    1
)
ORDER BY
  ad DESC NULLS LAST /* Generated by Cortex */;
