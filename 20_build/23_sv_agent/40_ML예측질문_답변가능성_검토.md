# ML 예측 질문 — Agent·Semantic View 답변 가능성 검토

> 분모 = 시트 「예측프롬프트」(통합본) 33문항 = 회원실 9 · 기획실 3 · 나눔마케팅본부 21.
> 시트 「기획실/회원실/나마본 ML예측 프롬프트」 3종은 같은 문항의 부서별 사본이다(셀 대조로 확인).
> 판정 근거 = JU93656 라이브 Agent 스펙 tool_resources·description(2026-10-03 실측) · **실행 스모크는 하지 않았다**(판정은 도구 정의 기준).
> 판정 = ⭕ 도구로 답한다 · △ 일부만(실적 대체·축 부족·지표 다름) · ✕ 데이터·모델이 없어 불가.
