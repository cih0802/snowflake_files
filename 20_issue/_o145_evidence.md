### 1-3. 라이브 재측정 (O145-B · 2026-09-08)

2026 목표 테이블의 부서(70개)에 대해 그 부서 소속 정기회원의 `CPR_DIV_CD` 종수를 셌다.

```sql
WITH GOAL_DEPT AS (
  SELECT DISTINCT DEPT_ID FROM GN_DW.BRONZE_CRM.TM_CM_MBER_DVLP_GOAL WHERE STDYY='2026'
), MEM AS (
  SELECT ACT_DEPT_CD AS DEPT_ID, CPR_DIV_CD, COUNT(*) AS MEMBERS
  FROM GN_DW.BRONZE_CRM.TM_MM_FDRM_MBER_INFO
  WHERE ACT_DEPT_CD IS NOT NULL GROUP BY 1,2
)
SELECT CORP_KINDS, COUNT(*) AS DEPTS, SUM(TOT_MEMBERS) AS MEMBERS FROM (
  SELECT G.DEPT_ID, COUNT(DISTINCT M.CPR_DIV_CD) AS CORP_KINDS, SUM(M.MEMBERS) AS TOT_MEMBERS
  FROM GOAL_DEPT G LEFT JOIN MEM M ON M.DEPT_ID = G.DEPT_ID GROUP BY 1
) GROUP BY 1 ORDER BY 1
```
