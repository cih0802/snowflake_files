## 🟢 O91 — `dbt build` 차단 3건 **전건 해소**(라이브) + 방법론 문서 7건 시정 (2026-08-20)

> 🟢 **이 절이 §O90 의 후속이고 `dbt build` 선결조건의 현행 정본이다.** §O90 은 「발견·기록」까지였고 **라이브 적용은 미이행**이었다.
> 🔒 라벨 = `id_collision_gate --next O` = **O91**(정의 최대 **90** ↔ 참조 최대 **90** 양축 일치) ⇒ 코드·라이브에 새기기 **전에**

### O91-4 🟢 `dbt build` 선결조건 2건 검증 완료 (2026-08-20 O91-B · 사용자 지시)

🔴 `99_NEXT §0-DDD ▣2` 가 `BLOCKING-5` 를 「build 전 확인 대상」으로 적은 것은 **과대였다** — 정본 `-012` §O91-B 에서 정정했다.
🟢 **부수 실증** — 사용자 런(`QUERY_ID 01c6819f-…-d6ba2` · 19:07:08→19:11:49 · **281초** · `GN_DW_ENGINEER`/`GN_DW_ETL_WH`)이
**`604 canceled`** 로 끝났다. 종전 실패는 15초에 `003001 (42501)` 이었다 ⇒ **RBAC 은 더 이상 차단하지 않는다**(O91-1 사후 실증).
