🟢 **부수 효과(현재는 이득)** = 그 TRUNCATE 덕분에 **원천 삭제행이 반영된다.** 이슈 `B` 고아 회원 제거가 이 모델에서도 집행됐다(3,654,929 → **3,654,658** · 고아 잔존 0). `merge` 자체에는 DELETE 절이 없으므로, TRUNCATE 가 없으면 그 제거가 일어나지 않는다.

🔴 **그래서 처방이 이슈 `B` 회신과 상충한다** — 선택지:

**처분**: ✅ **[2026-09-22 O180] 종결 — 사용자 결정 `ⓐ′` = 위 표의 ⓐ 를 개정해 「표준 패턴으로 정렬」.**

## ✅ O180-1 — O179 의 GOLD 팩트 `pre_hook` 제거가 컴파일을 깨뜨린 상태로 남아 있었다 (2026-09-22 O180 신규·종결)

> 🔴🔴 **판정** : 이 class 는 **한 세션에 4회 재발**했고 매번 눈으로는 통과했다.

**증상** = `Compilation Error in model FACT_EVENT_ATTENDANCE … invalid syntax for function call

**원인 4중** — 전부 「Jinja 는 파일 전체를 렌더한다」는 한 성질에서 나온다:

| # | 형태 | 결과 | 누가 |
|---|---|---|---|
| ㉠ | `config()` **안**에 `--` SQL 주석 | Jinja 가 `--` 를 연산자로 파싱 ⇒ 컴파일 에러 | O179(4파일) |

   ㉣ SQL주석 직후 공백제거형 주석 ㉤ 공백제거 닫기 직후 실행문 ㉥ 주석 구분자 개수 불균형.
