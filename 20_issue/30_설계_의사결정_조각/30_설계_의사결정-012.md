### 29-A. 결정 내용

1. `DIM_MEMBER_ACQUISITION`(획득 grain 1행/회원 · `SV_MEMBER_COHORT`·`SV_MEMBER_FEE` 가 사용)의
   캠페인 속성 = **회원 획득 시점 값으로 고정**(현재 `DIM_CAMPAIGN` 실시간 조인 → 동결값 전환).
2. `FACT_MEMBER_SPONSOR_BIZ`(약정 grain · `SV_MEMBER_SPONSOR_BIZ` 가 사용)의 대표캠페인 속성 =
   **약정(후원) 개시 시점 값으로 고정**.
3. 동결 대상 속성 = **12개 전체**(요건1·2의 9속성 + 추가 3속성). 사용자 확정 — *"3개 포함 전체 동결"*.

### 29-C. 구현 방향 (착수 전 — `dbt build` 는 `R4-1` 정지점)

1. `FACT_MEMBER_COHORT.sql` — 획득 사건(NEW/FALLBACK)에 대응하는 `CRM_MEMBER_DEV` 행에서 12속성을
   `ACQ_*_AT_ACQ` 로 함께 실어온다(현재는 `ACQ_CAMPAIGN_SK` 만 보유).
2. `DIM_MEMBER_ACQUISITION.sql` — `cmp.*`(`DIM_CAMPAIGN` 실시간 조인) 5축을 위 동결 컬럼으로 교체 +
   나머지 7속성(요건2 2 + 신규 UTM/공통브랜드 등) 신규 노출.
3. `FACT_MEMBER_SPONSOR_BIZ.sql` — 기존 `campaign_pick`(대표사건 선정)을 `CRM_MEMBER_DEV` 12속성과
   조인해 함께 실어온다(현재는 `CMPGN_CD`→`CAMPAIGN_SK` FK 만 보유).
4. `06_DDL.sql` 컬럼 추가 + 라이브 `ALTER TABLE ADD COLUMN`(`O98` 관례).
5. `05_3_SV_DDL_MEMBER_COHORT.sql`·`05_9_SV_DDL_MEMBER_FEE.sql`·`05_10_SV_DDL_MEMBER_SPONSOR_BIZ.sql` —
   `acq_campaign.*`/`fee.*`/`campaign.*`(실시간 조인) 참조를 동결 컬럼으로 재배선.
6. `dbt build --select FACT_MEMBER_COHORT DIM_MEMBER_ACQUISITION FACT_MEMBER_SPONSOR_BIZ+`(사용자 실행).
7. SV 재배포 + synonyms 유지 + `SEMANTIC_VIEW()` 스모크 검증(`O98`/`O99` 관례).
