# 운영계 업데이트 안내 (2026-10-26 반영)

## 한눈에 보기

  1. 부서 기준이 "현재 조직"으로 바뀌었습니다.
  2. 분석할 수 있는 축이 늘었습니다.
  3. 예측과 LTV를 보는 방식이 넓어졌습니다.
  4. Agent 답변 형식이 정리됐습니다.

## 1. 부서별 실적: 현재 조직 기준으로 집계

| 무엇이 바뀌었나 | 체감되는 변화 |
|---|---|
| 폐지되거나 개편된 부서의 실적을 **지금 있는 부서-팀**으로 합쳐서 보여줍니다 | "부서별 중단", "부서별 개발 실적", "목표·실적·달성율"을 물으면 **현재 조직도 기준**으로 답합니다 |
| 당시 부서 기준도 그대로 볼 수 있습니다 | 질문에 "당시 부서 기준"이라고 붙이면 옛 부서명으로 답합니다 |
| 귀속처가 없는 폐지 부서는 "(미매핑 폐지부서)"로 따로 묶어 보여줍니다 | 합계가 줄지 않습니다(빠지는 실적 없음) |
| 부서별 중단률은 분자와 분모를 **같은 현재 부서 기준**으로 계산합니다 | 흡수한 부서의 중단률이 부풀려지지 않습니다. 다만 이 중단률은 **약정 개수 기준(행 수)**입니다 — 공식 "(건)"(약정금액 ÷ 10,000)이 아니라 중단된 약정의 **개수** ÷ 전월말 활동 약정의 **개수**입니다. 공식 중단율(금액 ÷ 10,000 기준 · 분모 = 개발 + 전월말 활동)은 부서 축이 없는 캠페인·납입방식 단위로만 산출되고, 부서 단위 데이터에는 증액 개발분이 없어 같은 공식으로 맞출 수 없기 때문입니다. 소액 약정의 중단이 많으면 공식 중단율보다 높게 나올 수 있습니다. 답변에도 "약정 개수 기준"으로 표시됩니다 |

> ⚠️ 일부 폐지 부서는 **자동 추정**으로 귀속했습니다. 추정이 섞인 답변에는 "일부 자동 추정 귀속"이라는 안내가 붙습니다. 전달드린 귀속 검토표에 회신을 주시면 확정값으로 바꿉니다.

## 2. 새로 볼 수 있는 분석 축

| 영역 | 추가된 축 |
|---|---|
| 캠페인 | 캠페인 대상, 캠페인 유형 |
| 메시지 발송 | 발송 시점의 정보(스냅샷) |
| 예산 | 예산 항목 |
| 회원·후원 | 등록 부서, 기부 유형 코드 |
| 광고(영상·재방송) | 상위캠페인을 **코드와 이름으로 나눠** 관리합니다. 재방송 광고 중 일부가 캠페인 이름으로 마케팅캠페인에 연결됩니다 |

> ⚠️ "기부 유형"은 코드의 의미가 아직 확정되지 않아 **코드 값 그대로만** 보여줍니다. 의미를 알려주시면 이름으로 바꿉니다.

## 3. 예측과 LTV

| 항목 | 변화 |
|---|---|
| ML 회원예측(증액·중단·미납·회비) | 예측 결과를 **7개 축**으로 나눠 볼 수 있습니다. 세 Agent 모두에 연결돼 있습니다 |
| LTV 상한 | 고정 개월 수 대신, **관측 중인 회원의 평균 유지개월로 상한을 계산**합니다 |
| 광고비 인입경로 배분 | 광고비를 인입경로별로 **개발(건) 비중에 따라 배분한 추정치**를 볼 수 있습니다. 실제 집행 내역이 아니라 추정입니다 |
| 회원 개발사건 코호트 | 개발한 달 이후 0~12개월 동안의 경과를 추적해 볼 수 있습니다 |

> 예측과 배분 값은 Agent 답변에 **"추정"이라고 표시**됩니다.

## 4. Agent 답변 형식

- 표에 **소계와 합계 행을 붙이지 않습니다.** 전체 합계가 필요하면 표 아래 본문에 한 줄로 적습니다. 엑셀로 옮겨 합칠 때 두 번 더해지는 문제를 막기 위한 변경입니다.
- 코드 값 목록(예: 가입경로, 후원사업 구분)을 Agent가 더 정확히 알게 됐습니다. 원천에 새 값이 생기면 저희가 감지해서 바로 추가합니다.
- 모든 Agent의 출력 규칙(한글 열 이름, 소수 둘째 자리 반올림 등)을 하나의 공통 규칙으로 맞췄습니다.

## 5. 숫자는 그대로인 내부 정리

- 원천 코드 라벨을 프로그램 안에 박아 두지 않고 **매핑표로 관리**합니다. 라벨이 바뀌어도 빠르게 반영할 수 있습니다.
- 그 과정에서 "사단" 감사 문자가 "통합"으로 잘못 분류될 수 있던 규칙을 고쳤습니다. 지금까지 실제로 잘못 분류된 건은 없습니다.
- 광고 원천의 컬럼 이름 변경에 대응했습니다. 결과에는 영향이 없습니다.
- 폐지 조직을 판정하는 기준을 한 곳으로 모았습니다. Streamlit 화면의 조직 선택 목록도 이 기준을 씁니다.

1. **부서 귀속 검토표**: 자동 추정으로 귀속한 폐지 부서가 맞는지 확인 부탁드립니다.
