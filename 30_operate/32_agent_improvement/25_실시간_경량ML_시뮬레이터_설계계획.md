# 실시간 경량 ML 시뮬레이터 설계 및 구현 계획 (13차 Agent 개선)

## 1. 배경 및 목적
- **현행 (Layer 1 · 정본 배치 예측)**: `GN_DW.ML` 사전 연산 뷰(`ML_DVLP_FORECAST_V`, `ML_LTV_FORECAST_V`, `ML_MEMBER_RISK_V`, `ML_ONCE_CONVERSION_V`, `ML_INC_BY_MKTG_CMPGN_V`)를 통해 정형/배치 예측을 초저지연으로 제공.
- **확장 (Layer 2 · 온디맨드 실시간 시뮬레이션)**: 사전 뷰에 없는 비정형 시나리오(예: "광고비 20% 증액 시 예상 개발건수", "신규 예산 배분 시뮬레이션")에 대해 사전 확인 후 실시간 경량 ML 모델을 호출하여 추정치 제공.

## 2. 2단계 실행 아키텍처 (Hybrid Orchestration)
1. **1단계 (사전 연산 뷰 최우선 탐색)**:
   - 전사/캠페인 개발금액, LTV, 이탈위험, 전환가능성 등 사전 뷰 지원 질의는 즉시 `analyst_ml_*` 도구로 응답.
2. **2단계 (사전 뷰 부재 시 확인 가드레일)**:
   - 미지원 가상 시뮬레이션 질문 발생 시 즉시 실행을 차단하고 사용자에게 확인 질문 출력:
     `"이 항목은 사전 연산된 정규 지표가 아닙니다. 머신러닝 실시간 시뮬레이션 모델을 사용하여 추정치를 계산할까요? (적용 가정: 직전 N개월 추세 및 변동률 기반 · 모델 오차 존재 · 고정 확정값 아님)"`
3. **3단계 (사용자 승인 시 온디맨드 ML 도구 실행)**:
   - 사용자가 승인하면 Snowflake UDF / Stored Procedure 기반 경량 시뮬레이션 모델 실행 후 결과를 분리된 표와 함께 제시.

## 3. 단계별 구현 작업 계획

| 단계 | 작업 내용 | 산출물 / 대상 |

| Step 2 | 시뮬레이터 Serving 뷰 및 시맨틱 뷰 배포 | `GN_DW.SERVING.SV_ML_REALTIME_SIMULATOR` |
