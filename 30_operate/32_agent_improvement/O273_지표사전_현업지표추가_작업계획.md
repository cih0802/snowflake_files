## 5. 54번 파일 설계(초안 · 착수 시 개발계에서 문법·결과 검증)

```sql
USE ROLE GN_DW_ADMIN;
-- [0] 사전 — 현재 행수 · 광고 단독 행 범위 · 검색 권한(실행 전 기록)
SELECT COUNT(*) FROM GN_DW.SERVING.BIZ_DEFINITION_CORPUS;                       -- 개발계 기대 2,156
SELECT COUNT(*) FROM GN_DW.SERVING.BIZ_DEFINITION_CORPUS
 WHERE TRIM(TOOL_NAME) = 'analyst_ad' AND AGENT_SCOPE <> 'MARKETING';            -- 기대 0
SHOW GRANTS ON CORTEX SEARCH SERVICE GN_DW.SERVING.SEARCH_BIZ_DEFINITION;        -- AR_SRC_COMMON 포함 확인
--   + 새 CSV ↔ 표 DOC_ID 대조(스테이지 CSV 를 외부 조회로 읽어 EXCEPT · 착수 시 작성)

-- [1] 워크스페이스 CSV → OPS 스테이지(26번 [3] 과 같다)
-- [2] TRUNCATE + COPY(26번 [4] 와 같다)
-- [3] 검색 서비스 새로고침 — 🔴 CREATE OR REPLACE 금지(권한 소실 · R2)
ALTER CORTEX SEARCH SERVICE GN_DW.SERVING.SEARCH_BIZ_DEFINITION REFRESH;

-- [4] 검증
--   ① 행수 = 기대 2,163 ② 광고 단독 NOT_MARKETING = 0 ③ RT-31~37 7행 · AGENT_SCOPE = MARKETING
--   ④ SEARCH_PREVIEW 「최종 광고비」 1순위 = RT-31 ⑤ SHOW GRANTS ON CORTEX SEARCH SERVICE = [0] 과 동일
```

- 🔴 착수 시 확인할 것 = `ALTER CORTEX SEARCH SERVICE … REFRESH` 문법을 `cortex search docs` 로 확인(기억으로 쓰지 말 것).
