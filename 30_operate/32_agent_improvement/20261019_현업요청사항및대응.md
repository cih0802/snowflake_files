# 2026-10-19 현업 요청사항 및 대응

## 1. 요청 요지

> 예측 모델에 없는 축이라도, **실적 데이터에 매핑해서** 실적에서 볼 수 있는 것을
> 예측 데이터로도 조합해 보고 싶다.

| 순 | 원문 요청(요약) | 분류 |
|---|---|---|
| R1 | 중단회원과 후원기간대·후원금액대·납입방식 매칭 | 미매칭 보완 |
| R2 | 회비예측을 후원사업별·마케팅캠페인명별로 | 집계 예측 배분 |
| R3 | 회원 회비를 캠페인카테고리뿐 아니라 마케팅캠페인명·공통브랜드와 매칭 | 실적 매칭 |
| R4 | 개발·중단·미납·회비·활동이 서로 조인되는 것 | 회원 단위 통합 |

## 2. 답변 방식(Agent 표준)

| 라벨 | 의미 | 답변 문안 |
|---|---|---|
| 예측치 | 모델이 직접 낸 값 | 「머신러닝 OO 예측치입니다」 |
| 매칭 집계 | 회원 단위 예측 결과를 실적 축으로 나눈 값 | 「OO 예측 결과를 실적 특성으로 나눈 집계입니다」 |
| 추정치 | 집계 예측 × 실적 비중 · 확률 합 등 파생 | 「OO 예측 데이터를 기반으로 실적 비중(또는 확률)을 적용한 추정치이며 모델 예측치가 아닙니다」 |
| 추세 참고치 | 모델도 추정 근거도 없을 때 | 「직전 3개월 실적 평균 · 모델 예측 아님」(기존 O203 규칙) |

미매칭 보완 규칙:

- 결과의 (미매칭) 비중이 **50% 이상**이면 보완값(직전 12개월 최근 실적 → 약정 시점 획득값)으로 다시 집계한다.
- 보완 기준과 보완 전·후 미매칭률을 각주로 밝힌다.
- 50% 미만이면 (미매칭)을 별도 행으로 둔다.

## 3. 구조 선택

- **스타 스키마(GOLD 팩트·차원)는 그대로 두고**, SERVING 에 **예측 브리지 뷰**를 둔다.
- 하나의 통합 와이드 뷰는 만들지 않는다.
  - grain 이 섞인다(회원 · 후원건 · 카테고리×월 · 계열×월).
  - 회비 실적 형제 팩트를 합치면 이중계상이 생긴다(O45 실측 +18.5%).
- 브리지 2종:
  - **회원 브리지** = 회원 단위 예측 + 실적 축 + 실적 상태(매칭 · 추정 아님).
  - **배분 브리지** = 집계 예측 × 실적 비중(추정).
