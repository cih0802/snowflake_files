# [공지] 분석 Agent 별 조회 범위 변경 안내

안녕하세요. 데이터 원천별 접근 기준에 맞춰 분석 Agent 의 조회 범위를 아래와 같이 조정했습니다.

## 무엇이 바뀌나요

| Agent | 조회 가능 | 이번에 빠진 것 |
|---|---|---|
| 마케팅 분석 | 광고(대행사 리포트) · 예산·지출결의 · 회원·캠페인 · GA4 · 머신러닝 예측 | 없음 |
| 경영·전사 분석 | 예산·지출결의 · 사업목표 · 회원 월실적 · 서비스 발송 · 머신러닝 예측 | 광고비·광고 성과 · 광고비 증감 시뮬레이션 |
| 회원 분석 | 회원·회비·캠페인·서비스·행사 · 머신러닝 예측 | 광고비 증감 시뮬레이션 |

## 이렇게 이용해 주세요

- 광고비·매체별 성과·광고비 증감 시뮬레이션은 **마케팅 분석 Agent** 에서 조회해 주세요.
- 경영·회원 Agent 에 광고 관련 질문을 하시면 「광고 지표는 마케팅 분석 Agent 소관입니다」라고 안내합니다.
- 질문에 광고 외 내용(예산·회원 실적 등)이 함께 있으면 그 부분은 그대로 답합니다.

## 일정

- 개발 환경 반영 완료 · 운영 환경은 사전 점검 후 별도 안내드립니다.
