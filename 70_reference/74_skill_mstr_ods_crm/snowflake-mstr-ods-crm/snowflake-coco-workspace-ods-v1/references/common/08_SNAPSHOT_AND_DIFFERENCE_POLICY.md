# 현재 ODS와 MSTR_DW 월마감 차이 정책

## 기본 차이

- MSTR_DW는 특정 기준월의 마감·Snapshot 규칙으로 생성된 데이터일 수 있다.
- MSTR_ODS는 현재 운영 상태와 적재 시점의 데이터를 보여준다.
- 현재 ODS에서 과거월을 조회해도 당시 월말 상태가 자동으로 복원되는 것은 아니다.

## 화면 표시

현재값으로 과거 기간을 계산하면 다음을 화면에 표시한다.

- `현재 ODS 기준 재계산`
- 적용 조회기간
- 사용한 업무 이벤트 날짜
- 데이터 최신 적재시각
- 월마감 보고서와 차이가 발생할 수 있다는 설명

## 금지

- MSTR_DW 숫자에 맞추기 위한 임의 제외
- 과거 상태를 알 수 없는데 현재 상태를 과거 상태처럼 표시
- 차이를 SQL 오류로 단정
- 검증값에 맞추기 위한 상수 보정

## 차이 판정

수치 차이는 다음 중 하나로 분류한다.

1. 원천 적재 차이
2. Snapshot과 현재값의 시점 차이
3. 업무 정의 차이
4. JOIN·중복·미매칭 문제
5. 상태·날짜·NULL 처리 차이
6. 화면 필터 또는 Python 재계산 차이
