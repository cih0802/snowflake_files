# 신규 Streamlit 구축 요청 예시

## 예시 1: 회원·후원 현황

```text
$mstr-ods-crm-schema

현재 MSTR_ODS 데이터를 기준으로 회원과 후원 현황을 보여주는 새로운 Streamlit을 만들고 싶습니다.

조회기간, 법인, 부서, 후원사업으로 조회하고 싶습니다.
화면에는 고유 회원 수, 현재 후원 건수, 신규 후원 건수, 중단 회원 수, 중단 건수, 후원금액을 보여주세요.

같은 회원이 여러 후원을 가진 경우 회원 수와 후원 건수가 다르게 계산되어야 합니다.
현재 상태로 과거를 계산하는 경우 화면에서 그 사실을 알 수 있게 해주세요.

저는 영문 테이블명과 컬럼명을 모릅니다.
먼저 사용할 업무 데이터, 각 수치의 의미, 날짜 기준, 중복 위험을 설명해주세요.
구현 전에 제가 결정할 업무기준이 있으면 한국어 선택지로 최대 3개만 질문해주세요.
```

## 예시 2: 납입 현황

```text
$mstr-ods-crm-schema

월별 납입 현황 Streamlit을 새로 만들고 싶습니다.
기간, 법인, 부서, 납입방법으로 조회할 수 있어야 합니다.

요청 금액, 실제 납입 금액, 정상 납입 건수, 납입 회원 수, 실패 또는 미납 건수를 보고 싶습니다.
취소나 환불이 있는 경우 어떤 기준으로 제외되는지 먼저 설명해주세요.

과거월의 납입방법이 현재 결제수단으로 바뀌어 보일 가능성이 있는지도 확인해주세요.
바로 코드를 만들지 말고 먼저 데이터와 업무기준을 분석해주세요.
```

## 예시 3: 캠페인·이벤트 참여

```text
$mstr-ods-crm-schema

캠페인과 이벤트별 참여 현황을 보여주는 화면을 만들고 싶습니다.
캠페인명, 이벤트명, 기간, 부서로 조회하고 참여 회원 수와 참여 건수를 비교하고 싶습니다.

같은 회원이 여러 번 참여한 경우 회원 수와 참여 건수를 따로 보여주세요.
캠페인과 이벤트가 실제로 어떤 기준으로 연결되는지 먼저 확인하고, 직접 연결 근거가 없으면 임의로 묶지 마세요.
```
