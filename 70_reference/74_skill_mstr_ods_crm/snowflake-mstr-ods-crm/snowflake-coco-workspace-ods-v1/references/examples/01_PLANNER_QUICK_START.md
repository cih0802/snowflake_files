# 기획자용 빠른 시작

## 1. 반드시 첫 줄에 스킬을 입력합니다

```text
$mstr-ods-crm-schema
```

이 한 줄이 있어야 MSTR_ODS 기준의 테이블, JOIN, 집계, 개인정보, 검증 규칙을 적용합니다.

## 2. 개발 용어는 작성하지 않아도 됩니다

다음 내용만 업무 언어로 적으면 됩니다.

- 어떤 화면을 만들거나 변경하려는지
- 누가 어떤 목적으로 사용하는지
- 어떤 수치를 보고 싶은지
- 조회기간과 필요한 필터
- 수와 건이 각각 무엇을 의미하는지
- 기존 화면이나 엑셀에 비교할 값이 있는지
- 화면 모양만 바꾸는지, 계산 기준도 바꾸는지

영문 테이블명, 영문 컬럼명, 코드값, SQL, JOIN 방식은 적지 않아도 됩니다.

## 3. 가장 짧은 요청 예시

```text
$mstr-ods-crm-schema

현재 MSTR_ODS 데이터를 사용해서 월별 후원 중단 현황 화면을 만들고 싶습니다.
기간과 법인, 부서로 조회하고 중단한 회원 수와 중단된 후원 건수를 함께 보여주세요.

저는 영문 테이블명이나 컬럼명을 모릅니다.
먼저 사용할 데이터와 수치의 의미를 설명하고, 결정이 필요한 업무기준만 최대 3개 질문해주세요.
기준이 확정되기 전에는 코드를 만들지 마세요.
```

## 4. CoCo가 먼저 보여줘야 하는 답변

- 구현 가능 여부
- 사용할 업무 데이터의 한글 역할
- 수·건·금액·비율의 의미
- 날짜 기준
- 중복 가능성
- 현재 확정된 부분과 미확정 부분
- 기획자가 선택할 질문 최대 3개

CoCo가 처음부터 영문 컬럼이나 SQL만 보여주면 다음과 같이 요청합니다.

```text
기술적인 설명을 먼저 하지 말고, 기획자가 이해할 수 있는 업무용어로 다시 설명해주세요.
영문 테이블·컬럼·코드값은 내부 검증 내용으로만 사용하고 제가 선택하도록 묻지 마세요.
```
