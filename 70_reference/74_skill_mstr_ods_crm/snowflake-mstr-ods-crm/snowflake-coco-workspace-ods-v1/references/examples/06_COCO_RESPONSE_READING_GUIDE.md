# 기획자가 CoCo 답변을 확인하는 방법

## `완료`라고 해도 확인할 내용

- 사용한 데이터가 `GN_DW.BRONZE_CRM`의 승인 범위인지
- 화면의 한 행이 무엇을 의미하는지
- 회원 수와 건수가 구분되어 있는지
- 조회기간에 사용한 날짜가 무엇인지
- 현재 ODS 재계산 여부가 표시되는지
- 대표 기간 2개 검증값이 있는지
- 화면과 다운로드가 같은 값인지

## 다음 표현이 나오면 구현을 멈춰야 합니다

- `추정했습니다`
- `이름이 같아서 연결했습니다`
- `DISTINCT로 중복을 제거했습니다`
- `기존 숫자에 맞추기 위해 제외했습니다`
- `현재 상태를 과거에도 동일하다고 보았습니다`
- `GA 클릭으로 간주했습니다`

이때 다음과 같이 요청합니다.

```text
추정한 부분을 구현에서 제외하고 `자료 필요` 또는 `업무기준 확인 필요`로 다시 구분해주세요.
확인 가능한 Snowflake 구조와 업무 담당자가 결정해야 할 내용을 나눠서 보여주세요.
```

## 좋은 완료보고의 형태

| 구분 | 확인할 내용 |
|---|---|
| 판정 | 완료/검증 필요/업무기준 확인 필요/자료 필요 |
| 적용 기준 | 수·건·금액·날짜·상태·귀속 |
| 사용 원천 | 실제 데이터 위치와 한글 역할 |
| 검증 | 조건·기준값·결과값·차이·판정 |
| 변경 파일 | 어떤 파일을 왜 바꿨는지 |
| 남은 내용 | 기획자가 정할 내용 최대 3개 |
