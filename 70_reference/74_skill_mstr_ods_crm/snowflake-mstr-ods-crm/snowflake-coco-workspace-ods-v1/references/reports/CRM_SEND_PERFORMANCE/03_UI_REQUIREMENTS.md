# CRM 발송성과 Streamlit 화면 요구사항

## 필터

- 시작일과 종료일은 필수다.
- 발송구분 대 → 중 → 소 순서의 종속 필터를 제공한다.
- 상위 구분을 변경하면 하위 선택지를 다시 제한한다.
- 발송제목 검색을 제공한다.
- 필요한 경우 발송채널, 법인, 부서 필터를 제공한다.
- 조회 버튼을 누를 때만 데이터를 다시 조회한다.
- 초기화 버튼을 제공한다.

## 결과 표

다음 열 순서를 유지한다.

1. 발송구분(대)
2. 발송구분(중)
3. 발송구분(소)
4. 발송제목
5. 발송 수
6. 발송 성공 수
7. 클릭율(GA) 또는 승인된 대체 명칭
8. 서신 참여 수
9. 선물금 참여 수
10. 선물금 참여 건
11. 중단 회원 수
12. 중단 회원 건

## 표시

- 수와 건은 천 단위 구분기호를 적용한다.
- 비율은 승인된 소수점 자릿수와 `%`를 표시한다.
- 화면 상단에 조회기간, 적용조건, 데이터 기준, 최신 적재시각을 표시한다.
- 현재 ODS로 과거를 계산하면 `현재 ODS 기준 재계산`을 표시한다.
- 데이터가 없을 때 오류처럼 보이지 않도록 안내한다.

## 다운로드

- 화면과 동일한 조건·열·집계값을 사용한다.
- 화면과 별도의 Python 집계를 만들지 않는다.
- 개인정보와 내부 기술키를 제외한다.
- 파일명에는 화면명과 조회기간을 포함한다.

## 성능

- KPI, 표, 차트, 다운로드는 한 APP 결과를 재사용한다.
- 같은 대형 SQL을 여러 번 실행하지 않는다.
- 전체 회원 상세를 Streamlit 메모리에 올리지 않는다.
