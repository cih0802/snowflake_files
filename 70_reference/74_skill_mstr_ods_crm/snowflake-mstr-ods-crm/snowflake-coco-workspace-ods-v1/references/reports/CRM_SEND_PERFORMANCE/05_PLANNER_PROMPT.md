# 기획자용 CRM 발송성과 구축 요청문

한 번에 구현을 맡기지 않고 아래 1~4단계로 나누어 요청한다. 대괄호 안만 업무 언어로 작성하고, 모르는 항목은 `모름`이라고 적는다.

## 1단계: 화면 분석 요청

```text
$mstr-ods-crm-schema

새로운 `CRM 발송성과 및 참여현황` Streamlit을 만들고 싶습니다.
기존 MSTR_DW 화면을 복제하는 작업이 아니라 현재 MSTR_ODS 데이터를 기준으로 새로 구축하는 작업입니다.

[화면에서 확인하고 싶은 내용]
- 발송구분과 발송제목별로 발송 결과를 보고 싶습니다.
- 발송 후 클릭, 서신 참여, 선물금 참여, 후원 중단을 함께 비교하고 싶습니다.

[기본 조회조건]
- 기본 조회기간: [예: 최근 1개월]
- 발송일 기준: [실제 발송일 / 발송을 요청한 날 / 모름]
- 발송채널: [전체 / 이메일 / 문자·알림톡 / 우편 / 모름]
- 법인 또는 부서 범위: [전체 / 특정 범위 / 모름]
- 후속 행동 인정기간: [발송 후 7일 / 30일 / 다음 발송 전 / 모름]

[최종 표 열]
- 발송구분(대)
- 발송구분(중)
- 발송구분(소)
- 발송제목
- 발송 수
- 발송 성공 수
- 클릭율(GA)
- 서신 참여 수
- 선물금 참여 수
- 선물금 참여 건
- 중단 회원 수
- 중단 회원 건

[진행 방식]
바로 코드를 만들지 말고 먼저 다음 내용을 업무용어로 설명해주세요.

1. 어떤 업무 데이터를 사용할지
2. 각 지표를 어떤 의미로 계산할지
3. 중복이나 잘못된 연결이 생길 수 있는 부분
4. 현재 확정된 기준과 아직 결정할 기준
5. 제가 결정해야 하는 쉬운 질문 최대 3개

저는 데이터베이스의 영문 테이블명, 컬럼명, 코드값을 알지 못합니다.
그런 기술적인 값은 Reference와 실제 Snowflake 구조에서 직접 확인해주세요.
질문이 필요하면 업무적으로 선택할 수 있는 한국어 선택지로 물어봐 주세요.

핵심 기준이 확정되기 전에는 SQL이나 Streamlit을 먼저 만들지 마세요.
기준이 확정된 후에 데이터 계산 계층을 먼저 만들고, 검증한 결과를 Streamlit에 연결해주세요.
```

## 2단계: CoCo 질문에 업무기준으로 답변

CoCo가 영문 컬럼이나 코드값을 물으면 답하지 않고 업무 선택지로 다시 설명해 달라고 요청한다. 아래는 답변 형식 예시다.

```text
$mstr-ods-crm-schema

앞서 질문한 업무기준은 다음과 같이 결정합니다.

1. 발송 수: [발송 대상 회원 수 / 실제 발송 시도 건수 / 다른 기준]
2. 발송 성공 수: [최종 성공한 고유 수신자 수 / 성공 처리 건수 / 다른 기준]
3. 후속 행동 인정기간: [발송 후 7일 / 30일 / 다음 발송 전 / 다른 기준]

추가 원칙:
- 같은 회원이 여러 발송을 받았을 때 행동 귀속: [가장 최근 발송 / 최초 발송 / 모든 발송 / 모름]
- 취소·환불된 선물금: [제외 / 포함 / 모름]
- 클릭률 표기: GA 원천이 확인되지 않으면 `메일 링크 클릭률`로 바꿔주세요.

결정한 내용을 지표 정의표로 정리하고, 아직 구현을 막는 미확정 항목이 있는지 알려주세요.
기술적인 선택은 실제 Snowflake 구조와 Reference를 확인해서 처리해주세요.
```

## 3단계: 구현 요청

지표 정의표를 확인한 다음 사용한다.

```text
$mstr-ods-crm-schema

앞서 확정한 CRM 발송성과 지표 정의로 구현해주세요.

- 승인된 MSTR_ODS 원천만 사용해주세요.
- 먼저 재사용 가능한 데이터 계산 계층과 화면 전용 결과를 만드세요.
- KPI, 표, 차트, 다운로드는 같은 결과를 사용해야 합니다.
- 오픈·클릭·서신·선물금·중단 원시 데이터를 한꺼번에 연결해 곱집계하지 마세요.
- 현재 ODS로 과거를 재계산한다면 화면에 `현재 ODS 기준 재계산`과 적재시각을 표시해주세요.
- 개인정보는 기본 화면과 다운로드에서 제외해주세요.
- 기존의 다른 Streamlit과 공통 파일은 요청한 범위 밖에서 변경하지 마세요.

구현 후 변경 파일과 각 파일의 역할을 기획자가 이해할 수 있는 말로 설명해주세요.
```

## 4단계: 완료 검증 요청

```text
$mstr-ods-crm-schema

CRM 발송성과 화면을 완료 처리하기 전에 다음을 검증해주세요.

1. 데이터가 있는 서로 다른 대표 기간 2개
2. 발송요청 수, 수신자 수, 발송 성공 수
3. 오픈·클릭·서신·선물금·중단 연결 전후의 행 수 증가
4. 연결되지 않은 데이터 수와 중복키 수
5. 회원 수와 참여 건수의 구분
6. 전체 클릭률을 전체 분자 ÷ 전체 분모로 계산했는지
7. KPI, 표, 차트, 다운로드의 필터와 총계가 같은지
8. 개인정보가 화면과 다운로드에 노출되지 않는지

결과를 `조회조건 | 기준값 | 결과값 | 차이 | 판정` 표로 보여주세요.
검증을 통과하지 못한 항목이 있으면 완료라고 표시하지 말고 원인과 필요한 결정을 알려주세요.
```
