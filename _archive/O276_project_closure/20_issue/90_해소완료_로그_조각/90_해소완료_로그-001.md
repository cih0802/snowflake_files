🔴🔴 **이 실측이 O87 의 「손실 0 · 3.679% 중복 흡수」를 무효화한다**:
· **`EVENT_SEQ` 는 결정적이지 않다** — 정렬 튜플 동일 행이 **397,224건** 실재한다.

· **「손실 0」을 주장할 수 없다** — 기반 모델 `GROUP BY`(11컬럼 + 계보 3 + param pivot)가 접는 양은
  **0 ~ 233,272행 사이**이고 정확한 값은 모른다. 「흡수」가 아니라 일부는 **소멸**한다.
· **2024 상반기는 `ORDER BY` 첫 키가 전건 NULL** 이라 `NULLS LAST` 가 무의미하고 정렬이 사실상
  `SRC_FILE_NAME` 부터 시작한다. 그런데 **파일 내부에는 순서 정보가 없다** — 이것이 tie 의 원인이다.
· ⇒ 성립하는 것은 **`NOT NULL` 위반 해소**까지다. 그 이상은 `GA4-SEQ-1` 로 넘긴다.
