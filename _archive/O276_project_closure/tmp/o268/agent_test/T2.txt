- 클릭은 알림톡 템플릿 4종(AT006040 · AT005628 · AT006638 · AT006639)을 받은 회원들에게서 나왔습니다.

- **클릭 판정 방법:** 알림톡 원천 데이터에는 열람·클릭 기록이 없습니다. 그래서 수신 후 5일 안에 카카오 경로로 홈페이지에 들어온 기록(GA, 회원번호로 연결)을 클릭으로 보았습니다.
- **조건:** 클릭 링크의 utm 캠페인이 `25acpi_om_gift`인 경우만 셌습니다. 실제 클릭이 들어간 페이지는 `/app/event/25kaomgift/acpi2025.gn`입니다.
- **포함 범위:** 링크 조건으로만 걸렀기 때문에, 이 링크가 들어간 템플릿 4종을 받은 회원의 클릭이 모두 포함됩니다. 특정 템플릿 하나만 보려면 템플릿 ID를 알려 주세요.
- **회원수 계산:** 한 회원이 여러 번 눌러도 1명으로 셌습니다(중복 제외).
- **표본 수:** 12명으로 적어서 클릭한 회원의 특성이나 전략을 일반화하기는 어렵습니다.
- **더 볼 수 있는 것:** 템플릿별 클릭 회원수, 그리고 클릭한 회원의 5일 안 후원 중단·개발 여부를 함께 볼 수 있습니다.

원천: CRM(UMS) → BRONZE_CRM.SND_REQ_MST·TM_MS_MSG_AT_SNDNG·TD_MS_MSG_AT_SNDNG_DTLS + GA → GOLD.FACT_AT_GA_CLICK

--- SQL ---
WITH __atclk AS (
  SELECT
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), t AS (
  SELECT
    a.member_dk,
    a.days_from_send,
    a.template_id,
    a.landing_path
  FROM __atclk AS a
  WHERE
    a.utm_campaign = '25acpi_om_gift'
)
SELECT
  COUNT(DISTINCT member_dk) AS "링크 클릭 회원수(명)",
  COUNT(DISTINCT template_id) AS "템플릿 수(개)",
  LISTAGG(DISTINCT template_id, ', ') AS "템플릿 ID",
  LISTAGG(DISTINCT landing_path, ', ') AS "랜딩 경로",
  MIN(days_from_send) AS "최소 경과일",
  MAX(days_from_send) AS "최대 경과일"
FROM t /* Generated by Cortex */;
WITH __atclk AS (
  SELECT
    days_from_send AS click_days_from_send,
    landing_path AS click_landing_path,
    template_id AS click_template_id,
    utm_campaign AS click_utm_campaign,
    member_dk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
)
SELECT
  COUNT(DISTINCT a.member_dk) AS "링크 클릭 회원수(명)",
  COUNT(DISTINCT a.click_template_id) AS "템플릿 수(개)",
  LISTAGG(DISTINCT a.click_template_id, ', ') AS "템플릿 ID",
  LISTAGG(DISTINCT a.click_landing_path, ', ') AS "랜딩 경로",
  MIN(a.click_days_from_send) AS "최소 경과일",
  MAX(a.click_days_from_send) AS "최대 경과일"
FROM __atclk AS a
WHERE
  a.click_utm_campaign = '25acpi_om_gift' /* Generated by Cortex */;
