**계산 방법과 한계**
- 회원 LTV = 월평균 납입회비 × 기대 유지개월입니다. 두 데이터는 단위가 달라 하나로 합쳐 조회하지 않았습니다. 같은 캠페인카테고리 기준으로 각각 조회한 뒤 결과값을 곱했습니다.
- 기대 유지개월은 회원이 획득 후 평균적으로 얼마나 후원을 유지하는지를 생존분석으로 추정한 값이며, 아직 후원 중인 회원도 포함합니다.
  - 상한은 아직 후원 중인 회원의 평균 유지개월을 올림한 값으로, 현재 80개월입니다.
  - 무기한은 관측된 최대 기간과 상한 중 더 긴 기간까지 계산한 값이라 항상 상한 이상입니다.
  - 중단한 회원만의 평균 유지기간은 실제보다 짧게 나오므로 쓰지 않았습니다.
- 월평균 납입회비는 회비만 포함하고 기부금은 뺐습니다. 납입 회비를, 회비를 낸 회원별 회비월 수로 나눈 값입니다.
  - 기간은 전체 기간이며, 당월보다 뒤인 선납분과 회비월이 비어 있는 행은 뺐습니다.
- 캠페인카테고리는 회원을 처음 데려온(획득 시점) 캠페인 기준입니다.
- 회원 수가 적은 카테고리는 값이 불안정합니다. 예를 들어 위기가정(48명)은 유지개월이 80.00개월로 나옵니다. 그래서 회원 수 1만 명 이상인 카테고리만 표에 넣었고, 전체 값은 위 두 원천 표에서 볼 수 있습니다.
- 값이 '(미상)'인 행은 원천에서 캠페인카테고리가 비어 있는 회원입니다.

WITH __surv AS (
  SELECT
    axis_type,
    axis_value,
    cohort_members,
    rmst_cum
  FROM GN_DW.GOLD.FACT_MEMBER_COHORT_SURVIVAL
)
SELECT
  axis_value AS "캠페인카테고리",
  CAST(ROUND(cap_m, 2) AS DECIMAL(38, 2)) AS "유지개월(상한)",
  cap_n AS "상한(개월)",
  CAST(ROUND(unl_m, 2) AS DECIMAL(38, 2)) AS "유지개월(무기한)",
  members AS "회원수(명)"
FROM (
  SELECT
    __surv.axis_value,
    MAX(__surv.cohort_members) AS members,
    MAX(
      IFF(
        NOT __surv.ltv_cap_avg_active_months IS NULL
        AND __surv.ltv_cap_avg_active_months <> 9999,
        __surv.rmst_cum,
        NULL
      )
    ) AS cap_m,
    MAX(
      IFF(__surv.ltv_cap_avg_active_months <> 9999, __surv.ltv_cap_avg_active_months, NULL)
    ) AS cap_n,
    GREATEST(
      COALESCE(MAX(IFF(__surv.ltv_cap_avg_active_months = 9999, __surv.rmst_cum, NULL)), 0),
      COALESCE(
        MAX(
          IFF(
            NOT __surv.ltv_cap_avg_active_months IS NULL
            AND __surv.ltv_cap_avg_active_months <> 9999,
            __surv.rmst_cum,
            NULL
          )
        ),
        0
      )
    ) AS unl_m
  FROM __surv
  WHERE
    __surv.axis_type = '캠페인카테고리'
  GROUP BY
    __surv.axis_value
)
ORDER BY

WITH __fee AS (
  SELECT
    acq_campaign_type,
    month_key,
    paid_fee_billable,
    member_dk
  FROM GN_DW.GOLD.WIDE_MEMBER_FEE
)
SELECT
  acq_campaign_type AS "캠페인카테고리",
  paid AS "납입회비(원)",
  member_months AS "납입 회원월(건)",

FROM (
  SELECT
    __fee.acq_campaign_type,
    SUM(__fee.paid_fee_billable) AS paid,
    COUNT(
      DISTINCT IFF(
        __fee.paid_fee_billable > 0,
        __fee.member_dk || '-' || TO_CHAR(__fee.month_key),
        NULL
      )
    ) AS member_months
  FROM __fee
  WHERE
    __fee.month_key > 0
    AND __fee.month_key <= TO_NUMBER(TO_CHAR(CURRENT_DATE, 'yyyymm'))
  GROUP BY
    __fee.acq_campaign_type
)
ORDER BY
  paid DESC NULLS LAST /* Generated by Cortex */;
