- **산식:** 캠페인별 활동율(%) = 월말 활동(건) ÷ (누계 개발(건) + 연도초 활동(건)) × 100
  - 월말 활동(건): 2026년 9월 말 시점의 활동 약정금액 ÷ 10,000
  - 누계 개발(건): 2026년 1월 - 2026년 9월 MSTR 개발(건) 합계
  - 연도초 활동(건): 2026년 1월 시점의 활동 건수
- **캠페인 기준:** 여기서 캠페인은 후원 약정에 연결된 대표 캠페인입니다. 「그 달 후원 캠페인」과는 다른 기준입니다.
- **(미매핑):** 마케팅캠페인명이나 마케팅채널이 마스터에 연결되지 않은 건입니다. 전체 합계를 맞추기 위해 표에 그대로 남겼습니다.
- **해석 주의:**
  - 분모가 작은 조합은 활동율이 크게 흔들립니다. 일부는 100%를 넘습니다(예: 위기가정(선오) · 회원 103.14%).
  - 분모가 100건 미만인 조합은 참고로만 보시기 바랍니다.
  - 건수는 금액을 환산한 값이라 소수점이 있습니다.

--- SQL ---
WITH __fcm AS (
  SELECT
    base_month_key,
    campaign_sk,
    cum_dev_cnt,
    active_cnt,
    year_start_active_cnt
  FROM GN_DW.GOLD.FACT_CAMPAIGN_MONTHLY
), __campaign AS (
  SELECT
    marketing_campaign,
    mktg_channel_nm,
    campaign_sk
  FROM GN_DW.GOLD.DIM_CAMPAIGN
)
SELECT
  mc AS "마케팅캠페인명",
  ch AS "마케팅채널",
  act AS "활동(건)",
  cdev AS "누계 개발(건)",
  ysa AS "연도초 활동(건)",
  CAST(ROUND(rate, 2) AS DECIMAL(38, 2)) AS "활동율(%)",
  CAST(ROUND(tot_rate, 2) AS DECIMAL(38, 2)) AS "전체 활동율(%)",
  tot_act AS "전체 활동(건)"
FROM (
  SELECT
    COALESCE(__campaign.marketing_campaign, '(미매핑)') AS mc,
    COALESCE(__campaign.mktg_channel_nm, '(미매핑)') AS ch,
    SUM(__fcm.active_cnt) AS act,
    SUM(__fcm.cum_dev_cnt) AS cdev,
    SUM(__fcm.year_start_active_cnt) AS ysa,
    SUM(__fcm.active_cnt) / NULLIF(NULLIF(SUM(__fcm.cum_dev_cnt) + SUM(__fcm.year_start_active_cnt), 0), 0) * 100 AS rate,
    SUM(SUM(__fcm.active_cnt)) OVER () AS tot_act,
    SUM(SUM(__fcm.active_cnt)) OVER () / NULLIF(
      NULLIF(
        SUM(SUM(__fcm.cum_dev_cnt)) OVER () + SUM(SUM(__fcm.year_start_active_cnt)) OVER (),
        0
      ),
      0
    ) * 100 AS tot_rate
  FROM __fcm
  LEFT JOIN __campaign
    ON __fcm.campaign_sk = __campaign.campaign_sk
  WHERE
    __fcm.base_month_key = 202609
  GROUP BY
    1,
    2
)
ORDER BY
  act DESC NULLS LAST /* Generated by Cortex */;
