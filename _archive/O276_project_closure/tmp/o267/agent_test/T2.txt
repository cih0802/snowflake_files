Use logical dimension names.## ① 핵심 요약
- 알림톡 링크 `utm_campaign=25acpi_om_gift`를 알림톡 수신 후 5일 이내(수신 당일 포함)에 클릭한 회원은 **12명**입니다. GN_DW 기준입니다.
- 이 12명은 **5건**의 알림톡 발송에서 나왔고, 클릭일은 **2025-09-17 - 2026-06-17**입니다.

## ② 그래프
값이 하나뿐이라 그래프는 넣지 않았습니다.

## ③ ▼ 상세

지정 링크 클릭 회원수(명) | 대상 발송요청 수(건) | 최초 클릭일 | 최종 클릭일

- **어떻게 셌는지:** 알림톡을 받은 뒤 그날을 포함해 5일 안에 카카오 경로로 홈페이지에 들어온 기록(GA)에서, 링크의 utm 캠페인 값이 `25acpi_om_gift`인 클릭만 골랐습니다. 한 회원이 여러 번 눌러도 1명으로 셌습니다.
- **열람 판정:** 원천 데이터에 알림톡을 열어 본 기록이 없습니다. 그래서 링크를 누른 것을 열람으로 봤습니다. 링크를 누르지 않고 메시지만 읽은 회원은 숫자에 들어가지 않습니다.
- **대상 범위:** 메시지 형식이 알림톡인 발송만 셌습니다. 알림톡 전용 채널로 보낸 것과, 문자 시스템을 통해 알림톡으로 보낸 것이 모두 들어갑니다. 홈페이지 방문 기록(GA)이 쌓인 기간 밖의 발송은 셀 수 없습니다.
- **비율을 내지 않은 이유:** 이 링크가 담긴 알림톡을 몇 명이 받았는지 따로 세지 않았습니다. 클릭 비율이 필요하면 이 알림톡을 받은 회원수를 조회해 함께 드릴 수 있습니다.
- **해석 주의:** 12명은 표본이 작습니다. 이 숫자만으로 회원 특성을 일반화하기는 어렵습니다.
- 발송별·월별로 나눠 보거나, 클릭 뒤 5일·30일 안에 후원으로 이어진 회원수를 볼 수도 있습니다.

원천: CRM(UMS 발송) → BRONZE_CRM.TM_MS_MSG_AT_SNDNG·TD_MS_MSG_AT_SNDNG_DTLS → GOLD.FACT_AT_GA_CLICK

--- SQL ---
WITH __atclk AS (
  SELECT
    date_sk,
    member_dk,
    send_request_sk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT __atclk.member_dk) AS "지정 링크 클릭 회원수(명)",
  COUNT(DISTINCT __atclk.send_request_sk) AS "대상 발송요청 수(건)",
  MIN(__date.full_date) AS "최초 클릭일",
  MAX(__date.full_date) AS "최종 클릭일"
FROM __atclk
LEFT JOIN __date
  ON __atclk.date_sk = __date.date_sk
WHERE
  __atclk.utm_campaign = '25acpi_om_gift'
  AND __atclk.days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
WITH __atclk AS (
  SELECT
    days_from_send AS click_days_from_send,
    utm_campaign AS click_utm_campaign,
    date_sk,
    member_dk,
    send_request_sk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT __atclk.member_dk) AS "지정 링크 클릭 회원수(명)",
  COUNT(DISTINCT __atclk.send_request_sk) AS "대상 발송요청 수(건)",
  MIN(__date.full_date) AS "최초 클릭일",
  MAX(__date.full_date) AS "최종 클릭일"
FROM __atclk
LEFT JOIN __date
  ON __atclk.date_sk = __date.date_sk
WHERE
  __atclk.click_utm_campaign = '25acpi_om_gift'
  AND __atclk.click_days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
