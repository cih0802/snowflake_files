Use logical dimension names.**① 핵심 요약**
- 알림톡 템플릿 AT006040을 받은 회원 중 수신 후 5일 이내에 그 템플릿 링크를 클릭한 회원은 **14명**입니다(GN_DW 기준).
- 이 클릭은 모두 2025-09-17 하루에 나왔고, 발송요청 2건에서 생겼습니다.

**▼ 상세**
- **집계 방식:** 알림톡 클릭 기록에서 템플릿 ID가 AT006040이고 수신일로부터 0-5일 사이(당일 포함)에 클릭한 행만 골랐습니다. 회원수는 중복을 뺀 고유 회원 수입니다.
- **클릭 판정 기준:** 원천에는 알림톡을 열어 본 기록이 따로 없습니다. 그래서 수신 후 카카오 경로로 홈페이지에 들어온 GA 링크 클릭(GA 회원번호와 회원번호를 맞춘 것)을 클릭으로 봤습니다.
- **빠질 수 있는 클릭:** GA에서 회원번호가 확인되지 않은 클릭과 GA 적재 범위 밖의 클릭은 세지 못했습니다.
- **분모:** 이번 결과에는 같은 템플릿을 받은 전체 회원수가 없습니다. 그래서 클릭 비율은 내지 않았습니다.
- **표본 수:** 14명은 30명이 안 되는 작은 표본입니다. 이 숫자만으로 클릭 회원의 특성을 일반화하기는 어렵습니다.
- **더 볼 수 있는 것:** 같은 템플릿을 받은 전체 회원수와 클릭 비율, 클릭 회원 중 5일 안에 후원을 중단하거나 증액한 회원 수를 이어서 조회할 수 있습니다.

원천: CRM(UMS) → BRONZE_CRM.TM_MS_MSG_AT_SNDNG·TD_MS_MSG_AT_SNDNG_DTLS + GA4 → GOLD.FACT_AT_GA_CLICK

--- SQL ---
WITH __atclk AS (
  SELECT
    date_sk,
    member_dk,
    send_request_sk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT a.member_dk) AS "링크 클릭 회원수(명)",
  MIN(d.full_date) AS "최초 클릭일",
  MAX(d.full_date) AS "최종 클릭일",
  COUNT(DISTINCT a.send_request_sk) AS "발송요청 수(건)"
FROM __atclk AS a
LEFT JOIN __date AS d
  ON a.date_sk = d.date_sk
WHERE
  a.template_id = 'AT006040'
  AND a.days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
WITH __atclk AS (
  SELECT
    days_from_send AS click_days_from_send,
    template_id AS click_template_id,
    date_sk,
    member_dk,
    send_request_sk
  FROM GN_DW.GOLD.FACT_AT_GA_CLICK
), __date AS (
  SELECT
    full_date,
    date_sk
  FROM GN_DW.GOLD.DIM_DATE
)
SELECT
  COUNT(DISTINCT a.member_dk) AS "링크 클릭 회원수(명)",
  MIN(d.full_date) AS "최초 클릭일",
  MAX(d.full_date) AS "최종 클릭일",
  COUNT(DISTINCT a.send_request_sk) AS "발송요청 수(건)"
FROM __atclk AS a
LEFT JOIN __date AS d
  ON a.date_sk = d.date_sk
WHERE
  a.click_template_id = 'AT006040'
  AND a.click_days_from_send BETWEEN 0 AND 5 /* Generated by Cortex */;
