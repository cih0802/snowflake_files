# N03. 통합 데이터 사전 (카탈로그)

본문 = `N03_통합데이터사전.xlsx`(시트 통합사전 · 요약) · `N03_통합데이터사전.html`(브라우저에서 열고 검색창에 지표·SV·테이블 이름 입력) · `N03_통합데이터사전.csv`(같은 내용 · 비교용 · 🔴 계보 5열(SV_base·GOLD·SILVER·BRONZE·기타상류)은 한 줄 2000자 상한 때문에 400자에서 끊고 「… 외 N개」를 붙였다 — 전체 목록은 xlsx·html 에 있다).

지표 1행에서 **지표 → 산식 → Agent 도구 → SV 필드·식 → SV base → GOLD → SILVER → BRONZE → 지표 원천 파일**을 끝까지 잇는다. D01·D04·D06·D08·D09 를 합친 것이며 새 사실을 만들지 않는다.

## 1. 열

| 열 | 출처 | 뜻 |
|---|---|---|
| DOC_ID · 묶음 · 지표 · 정의 · 산식 · 대응상태 · 적용Agent · 지표원천 | D01 | 현업 지표사전 원문(코퍼스 경유) |
| 도구 · 대상SV | D01 · D09 | 이 지표를 답하는 Agent 도구와 그 도구가 읽는 SV |
| SV필드 · 필드종류 · SV식 | D01 · D08 | `SV.논리테이블.필드` · 메트릭이면 식, 아니면 「차원·사실」 |
| SV_base | D06 `SV base` | 그 논리테이블의 물리 객체 |
| GOLD · SILVER · BRONZE · 기타상류 | D06 뷰 의존 · dbt ref · dbt source 상향 추적 | SV_base 를 포함한 상류 전부(레이어별 `|` 구분) |
| 추적범위 | 생성기 | 필드 · 필드(base 미해결) · SV 전체 · 없음 |

## 2. 결과 (IW20760)

| 항목 | 지표 |
|---|---|
| 지표 | 237 |
| 추적범위 = 필드 | 132 |
| 추적범위 = 필드(base 미해결) | 6 |
| 추적범위 = 없음(도구 배선 없음) | 99 |
| GOLD 도달 | 130 |
| SILVER 도달 | 132 |
| BRONZE 도달 | 128 |

- 「없음」 99 = D01 「산식 미등록」 99 와 같은 지표들이다(D01 §2).
- 「필드(base 미해결)」 6 = `RT-14`·`RT-15`·`RT-16`·`RT-30`·`MET_CMN-59`·`MET_CMN-60`. 계보 결함이 아니다 — 오버레이의 `SV_FIELD` 가 식별자 1개가 아니라 **여러 필드 나열이나 서술**(예: `(질문 지표의 metric)`)이라 기계로 풀 수 없다. 이 6행은 D09 의 도구 설명을 보고 사람이 따라간다.
- GOLD 미도달 2 = `SV_MSTR_SPNSR_DVLP` 필드(`MET_CMN-4`·`-124`) — base 가 `SERVING.MSTR_SPNSR_DVLP_V` 이고 상류가 `MSTR` 스키마다(기타상류 열). MSTR 는 GOLD 를 거치지 않는 별도 경로다(프로시저 적재 · D07). 이 2행도 MSTR 뷰의 의존 간선으로 SILVER·BRONZE 열은 채워진다.
- BRONZE 미도달 4 = GA 계열 `MET_CMN-99`·`-100`·`-101`·`-103`(`SV_GA_BEHAVIOR` 의 EVT·SRC). GA 는 원천이 외부 Python 적재 `SILVER.BIGQUERY_REFINED_DATA` 라 BRONZE 가 없는 것이 정상이다(D06 L-1).

## 3. 쓰는 법

- 「이 지표 숫자가 이상하다」 → html 에서 지표 검색 → `SV식` 으로 계산을 확인 → `GOLD`·`SILVER` 에서 적재 테이블을 찾아 A6 런북으로 넘어간다.
- 「이 테이블을 바꾸면 어떤 지표가 흔들리나」 → html 검색창에 테이블 이름을 넣는다(역방향 조회).
- 계보는 **테이블 단위**다. 컬럼 단위 계보는 없다(D06 §4).
