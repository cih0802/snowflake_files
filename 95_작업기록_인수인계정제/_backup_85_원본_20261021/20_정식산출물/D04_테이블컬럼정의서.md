## 2. 레이어별 규칙

| 레이어 | 구조 정본 | 데이터 적재 | 명명·키 |
|---|---|---|---|
| BRONZE | 원천 적재 담당(외부팀 · LOADER) | 원천 시스템 → 외부 적재 · 일부 `_STDR_YM` 월 파티션 재적재 키 | 원천 물리명 그대로 · SQL 식별자로 SV 에 쓰지 않는다 |
| SILVER | `08_SILVER_테이블DDL` | dbt(TRUNCATE + append 전량 · BIGQUERY 계열은 롤링 창) | 원천 도메인 접두(CRM_*·BIGQUERY_*·AGENCY_*·ERP_*) |
| GOLD 테이블 | `06_DDL.sql`(타입·FK·COMMENT) | dbt(dim = merge · fact = append) | `DIM_*`·`FACT_*` · 대리키 `*_SK`(Unknown = 0) |
| GOLD 뷰 | dbt `_wide_schema.yml`(COMMENT 포함) | dbt view | `WIDE_*` |
| SERVING | SV·ML 뷰 DDL 파일(05_*·21~26) | 뷰 · 코퍼스 적재 | `SV_*` · `ML_*_V` · `MSTR_*_V` |
| MSTR | MSTR 이관 DDL(00~05) | 프로시저 CALL(dbt 아님) | 원 MSTR 명 유지 |

- NULL 표기 규약: `(미매핑)` = 차원 조인 실패(SK=0) · `(해당없음)` = 개념 부재 · NULL = 값 없음. 세 값은 서로 대체하지 않는다(지침 R2-7).
