# 개인정보 및 화면 노출 정책

## 기본 제한 정보

- 회원·아동 이름
- 전화번호, 휴대전화, 팩스
- 이메일, 주소, 우편번호
- 생년월일, 주민등록 관련 값
- 결제정보, 계좌정보, 인증정보
- 메시지·서신 본문
- 아동 사진, 파일 경로, 이미지 URL

## Streamlit 기본 원칙

- 집계 결과만 표시한다.
- 내부 JOIN 키는 화면과 다운로드에서 숨긴다.
- 개인정보가 없는지 다운로드 파일도 별도로 점검한다.
- 회원 상세가 꼭 필요하면 목적, 사용자 권한, 최소 컬럼, 마스킹 방식을 먼저 확인한다.
- 개발·검증 로그에 개인정보 샘플을 출력하지 않는다.
