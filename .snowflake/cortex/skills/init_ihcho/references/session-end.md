## 1. 세션 종료 절차

```
python3 scripts/doc_census.py                     # stale 0 · 여유 확인
python3 scripts/session_brief.py --write          # 00_BRIEF 재생성(게이트 포함)
python3 scripts/gen_measure_backlog.py --write    # 실측필요 항목 재생성
python3 scripts/decision_closure_gate.py          # 내 결정을 인용한 정본이 stale 인가(경고)
```

**음성 테스트 전건 실행** — 🔴 목록을 적지 마라(적으면 stale). 한 줄로 돈다:
```
for t in scripts/test_*.py; do python3 "$t" >/tmp/t.out 2>&1; r=$?; [ $r -ne 0 ] && echo "🔴 $t rc=$r"; done
```
🔴🔴 **종료코드를 파이프 뒤에서 읽지 마라**(`R0-8-2`) — 종전 문안 `python3 "$t" | tail -1` 은
`$?` 가 `tail` 의 것이어서 **실패를 감췄다**(실해 = 「14종 전건 exit 0」 발행 ↔ 재측정 시 rc=1 이 4건).
⚠️ **인자가 필수인 도구는 게이트가 아니다** — 무인자 크래시를 FAIL 로 세지 마라(규약 exit 2).

🔴 **골든을 재발행할 때는 `--reason` 을 반드시 준다**(`index_row_gate` · `doc_heading_gate` ·
`test_generators` · `rename_stale_gate --baseline`). 사유 없는 발행은 「정당한 재발행」과
「FAIL 을 덮은 발행」을 사후에 구별할 수 없게 만든다 ⇒ 🟢 발행 전에 **차이를 전량 분해**하고
**실유실 0** 을 확인한 근거를 사유에 적어라.

**정본 3곳을 갱신한다** — 🔴 셋은 서로 대체물이 아니다:

| 정본 | 무엇 | 방법 |
|---|---|---|
| 원장 §1 대시보드 행 | 상태 | 조각을 `edit` → `split_doc.py <허브> --republish --expect "<라벨>"` · 🔴 **1,900자 이내** · 🔴 **열 수(헤더와 같은 파이프 수)를 맞춰라** |
| `01_세션이력` 항목 | 서술·경위 | `split_doc.py 20_issue/01_세션이력.md --rollover --entry-file <파일>` |
| `99_NEXT_SESSION` 인수인계 절 | 다음 세션이 읽을 것 | 🔴 「여기서 시작한다」를 새로 쓰고 **이전 절의 그 문구를 `~~취소선~~`** 으로 승계 표시 · 🟢 **절 라벨에 세션 라벨을 병기**(`0-TTTT/O167`) · 🔴 기존 라벨을 소급 개명하지 마라 |

⚠️ 승계 표시를 빼먹으면 브리핑이 **날짜로만** 판정해 옛 절이 현행으로 뽑힌다.
⚠️ 그 취소선 편집은 `doc_heading_gate` 에 「제목 유실 1건」으로 잡힌다 — **정상 관례**이므로
실유실 0 을 확인하고 `--update-golden --reason "<승계 표기>"` 로 발행한다.
⚠️ 새 절을 쓰면 그 조각이 상한에 걸릴 수 있다 ⇒ **압축 또는 재균형**(재균형은 `R4-4-3` 승인).
🔴 **긴 절은 별도 파일(`tmp/_o1NN_entry.md`)에 먼저 쓰고 붙여라** — 실사고에서 복구 수단이
「작성자가 다시 쓰는 것」뿐이었다(스냅샷에도 없었다).

### 1-1. 「닫았다」고 쓰기 전에

**판정식** = 「닫았다·완료·재정의」를 쓸 때마다 **그 문구가 가리키는 정본 행/절을 열어 고쳤는가?**
착수표면 `99_NEXT` 착수 순서의 **그 행**(순 셀 취소선 + 대체 처방) · 이슈면 원장 §1 행 ·
결정이면 `30_설계` 절 · dbt 항목이면 문서50 절.

**확인 방법(둘 다)**:
1. `session_brief.py --write` 후 **열린 착수표 건수가 줄었는지** 본다. 줄지 않았다면 **닫지 못한 것이다**.
   🔴 추출기·조각 경계를 건드린 세션은 **건수 비교 대신 ② 를 근거로** 삼아라(경계가 바뀌면 수가 움직인다).
2. `grep -n "<그 항목 표시>" 99_NEXT_SESSION_조각/*.md` 로 **취소선 표기를 눈으로 확인**한다.

🟢 취소선 관례 = `| ~~⑥~~ | ~~옛 제목~~ ➔ 🟢 [세션 라벨] 새 처방 |`.
🔴 **행을 지우지 마라**(좌표 인용 안정성) — 취소선 + 대체 문장으로 남긴다.
🔴 **「하지 마라」를 본문에 적어라** — 다음 세션은 옛 처방을 그대로 실행할 수 있다.

## 2. 문서 유지 도구 (정본 = `00_guides/01_문서분할_규약.md` `R1-6` 계열)

| 도구 | 용도 | 필수 인자 · 조문 |
|---|---|---|
| `split_doc.py <허브> --republish` | 조각 편집 후 허브 재생성 | 🔴 **`--expect TOKEN`**(`R1-6-23`) |
| `split_doc.py <허브> --rollover --entry-file <파일>` | append 형(이력·`90`)에 항목 추가 | 조각을 직접 열지 않는다(`R1-6-15`) |
| `split_doc.py <허브> --rebalance --fill 0.7` | 조각이 상한(300줄/40KB)에 근접할 때 재분할 | 🔴 `R4-4-3` 승인 · 용량 불변식 `R1-6-14` |
| `split_doc.py <문서> --to-outdir <이름>_조각 --apply` | 형제 조각을 폴더로 이전(`R1-6-21`) | 🔴 **`_조각` 접미 필수**(`R1-6-10` — 스테이지 「폴더」는 경로 접두라 없으면 허브까지 지워진다) |
| `session_brief.py --write` | `00_BRIEF.md` 생성(게이트 포함) | — |
| `gen_measure_backlog.py --write` | `92_실측필요_후속작업.md` 생성 | — |
| `retire_rows.py --apply` | 원장 **표 행의 장문 셀**을 포인터화 | 🔴 승인 · **절은 못 옮긴다** · `R2-8-1` 토큰 대조 blocking |
| `retire_sections.py --apply` | 닫힌 절의 **본문만** 이관(제목 보존 · `R1-6-19`) | 🔴 승인 · dry-run 기본 · ⚠️ **「닫힘」은 제목 이모지 판정일 뿐이다**(`R1-6-24`) — 은퇴 전에 그 절을 읽어라 |
| `split_narrative.py` | 조문의 경위 서사를 `91_사고사례집.md` 로 이관 | 처방(🟢/⚠️)은 옮기지 않는다(옮기면 조문이 지시를 잃는다) |
| `doc_coord_gate.py` | 인용 좌표 실재(`R1-6-22`) | — |
| `stage_mount_size_gate.py` | 마운트 ↔ 스테이지 **크기 패딩식** 대조 | 🔴 md5 대조는 원리적 불가(암호화 blob 해시) |

🔴 **`--expect` 토큰은 「연속 리터럴」이다** — 마크다운 장식(`**`·백틱)이 끼면 부분문자열이 아니라
**신선도 FAIL** 이 난다(파일은 정상이고 선언이 틀린 경우다). 🟢 장식 없는 구간에서 고른다.
🔴 **가드가 멈추면 파일보다 토큰을 먼저 의심하라.**
🔴 **유지 연산 직후의 게이트 FAIL 을 곧바로 믿지 마라**(`R1-7-3` · 낡은 뷰) — **2~3회 재실행 후 판정**하고
그 사이에 「내가 깼다」로 문서를 고치지 마라.
🔴 **원장 §1 행은 1,900자 이내**로 쓴다(초과하면 계속 재작성하게 된다) — 상세는 처음부터 이력으로 보낸다.
