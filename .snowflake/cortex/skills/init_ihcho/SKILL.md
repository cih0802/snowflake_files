# init_ihcho — 세션 초기화

세션 최초 턴에 1회 실행한다. 목적 = ㉠ 가드 활성화 → ㉡ 지침 로드 → ㉢ 열린 작업 확보 → ㉣ 단답형 브리핑.

## Step 0. 브리핑 생성을 백그라운드로 띄운다 (🔴 첫 도구 호출)

🔴🔴 **다른 어떤 도구(`read`·`wc`·`grep`)보다 먼저** 실행한다 — 생성이 2분을 넘는다.

`bash` 툴에 **`run_in_background=true`** 로 아래 한 줄을 넘기고 **반환된 shell id 를 기억**한다:
```
cd /workspace && python3 scripts/session_brief.py --write </dev/null >/tmp/session_brief.out 2>&1; echo "BRIEF_RC=$?"
```
- 🔴 `timeout 60` 을 붙이지 마라(60초에 죽어 `rc=143` · background 는 G1 의 예외).
- 🔴 **기다리지 않는다** — 곧바로 §1 → Step 1 로 간다. 완료 대기는 Step 2 에서 한다.

## §1. 상시 가드 (즉시 적용)

### G1. 셸·판정 안전 (지침 `R0`)

- 복합구문(`for`/`if`/heredoc/따옴표)은 **한 명령 문자열 안에서 완결**한다(미완결 = 무한 대기).
- 셸 루프 대신 `ls -d a b c` · `find -L /workspace/ …` · `grep -rn pat a b c` 같은 **단일 명령**.
- 모든 명령에 `timeout 60` + `</dev/null`. 장기 작업은 background 실행 후 폴링(Step 0).
- 타임아웃 시 **같은 명령을 재시도하지 않고**(`R0-6`) 구문 점검 → 최소 명령 → 경로 분해로 복구한다.
- dbt 명령에는 셸 연산자를 쓸 수 없다. `--project-dir` 로 경로를 넘긴다.
- 🔴🔴 **`R0-8`「0건」은 `rc` 를 먼저 보라.** `rc=0` 일 때만 「없다」 — `143`·`124`·`2` 는 **미판정**이다.
- 🔴 **`R0-8-2` `rc` 를 파이프 뒤에서 읽지 마라** — `>/tmp/x.out 2>&1` 로 받고 `rc=$?` 를 먼저 잡는다.
- 🟢 정본 검색 분모 = `20_issue/` · `99_NEXT_SESSION_조각/` · `00_guides/` · `scripts/`.
  `_archive/` 는 `ls _archive/ | grep <문서명>` 으로 **파일명부터** 좁힌다(대용량 · 60초 초과).

### G2. 읽기 — 전량 확보 (지침 `R1-3`)

**읽기로 결정한 파일**에 적용한다(무엇을 읽을지는 §2 Step 2 가 정한다 — 「전부 읽어라」가 아니다).

- 처음부터 끝까지 읽는다. 일부만 읽고 나머지를 추론하지 않는다.
- `read` 는 1회 2000줄·1줄 2000자까지 — 잘리면 `offset`/`limit` 으로 **끝까지** 이어 읽는다.
- `timeout 60 wc -l <경로>` 로 줄 수를 먼저 재고 호출 수를 자가 검증한다.
- 내용 파악은 `read` 툴. `cat`/`head`/`tail` 은 절단으로 내용을 잃는다(bash 는 줄 수·크기 확인 전용).
- 부분 읽기는 **사용자가 구간을 지정한 경우에만** 허용하고 그 사실을 응답에 적는다.

### G3. 쓰기 — 한 줄 2000자 가드 (지침 `R1-5` · `R1-5-1`)

- **한 줄 2000자 초과 금지**(목표 1000자). 긴 문장은 의미 단위 개행 · 표는 행마다 · SQL 은 절 단위.
- 긴 나열은 쉼표 대신 **불릿·표 행**으로.
- **쓰기 직후** `timeout 60 python3 scripts/line_len.py <경로> …` → 🟢 PASS.
- 🔴 `awk 'length($0)>2000'` 금지 — BusyBox awk 는 **바이트**를 센다(한글 오탐). 판정은 문자 기준.

### G4. 쓰기 — 파일 안전 규약 (정본 = `00_guides/02_파일쓰기_안전규약.md`)

| 조문 | 금지문 · 처방 |
|---|---|
| `R1-7-1` | **전체 재작성(`write`) 금지 · 부분 치환(`edit`) 기본**(코드 파일 포함). `write` 는 신규 파일 전용. 부득이 전체를 썼다면 즉시 꼬리 되읽기 · `py_compile` · 해시 대조 |
| `R1-7-2` | **쓰기 전 해시 안정성 확인(blocking)** — 2회 읽어 크기·SHA256 동일해야 착수 · 🔴 **같은 파일에 `edit` 를 병렬로 보내지 마라** |
| `R1-7-3` | **「손상」 판정 전에 2~3회 재읽어 해시 대조**(torn read 오판 방지) |
| `R1-7-4` | **원장 표를 건드렸으면** `python3 scripts/index_row_gate.py` · FAIL 을 `--update-golden` 으로 덮지 마라 · 낡은 행은 **행 키를 보존한 채 내용 대체** |
| `R1-7-5` | **토큰 1개로 「보존」을 단정하지 마라** — 단정 대상은 **행 키 집합** |
| `R1-7-6` | **파일 단위 discard 금지**(되돌릴 수 없다 · 타 세션 변경까지 지운다) · `ALTER WORKSPACE … ABORT` 는 승인 없이 금지 |
| `R1-7-7` | **`rm -rf` 도 파괴 명령** — 스테이지 「폴더」는 경로 접두 ⇒ 삭제 전 `os.listdir` 로 나열 · **파일 개별 삭제** · 삭제 후 `os.listdir` + `cortex ws ls` 두 축 확인 |
| `R1-7-8` | **`edit` 앵커는 직전 줄까지 · 긴 표 행은 행 전체(끝 `\|` 까지)** · 너무 길면 python 줄 인덱스 치환 · 직후 `doc_heading_gate` + `index_row_gate` · 조문·절은 **번호 순서 말미에** |
| `R1-7-9` | **백틱·`$`·`!` 를 포함한 본문은 셸을 경유시키지 않는다** — `write`/`edit` 툴 또는 스크립트 파일 · quoted heredoc·`python3 -c` 도 셸 경유다 · 쓴 뒤 되읽어라 |
| `R1-7-10` | **스냅샷은 `scripts/snapshot_util.py` 만 경유**(라벨 = `--label` → `SESSION_LABEL` → `UNLABELED` · 지난 라벨을 기본값으로 두지 마라 · 덮지 않는다 · `archive=` 를 넘겨라) |

🔴 **이 마운트는 `cat >>`(append)를 지원하지 않는다**(stderr 만 나고 조용히 유실).
⇒ 파일 추가는 `write` 툴 또는 python 전량 쓰기 + **직후 토큰 재검사**. 🟢 「썼다」와 「닿았다」는 다르다.

### G5. 독해 기록 의무 (지침 `R1-3-7` · `R1-3-7-a` · `R1-3-7-b` · `R1-3-7-c`)

`read` 미반환은 **조용하다** = ㉠ `edited out to manage context size` ㉡ `Output too large` ㉢ 미리보기·꼬리만.

- **호출한 사실은 확보한 사실이 아니다.** 매 호출 직후 본문 도착을 확인한다.
- 미반환이면 `limit` 을 60~100줄로 줄여 재호출한다. 미반환 파일·좌표·건수를 숫자로 적는다
  (판정식 = 재호출 건수 ≥ 미반환 건수 · 못 채우면 「도착 실증 · 복구 절차 미실행」으로 적는다).
- 복구 실패 파일은 **미독으로 명시**하고 그 소관 수치를 인용하지 않는다.
- 🔴 **대체 근거 금지** — 대화 로그·이전 응답·기억은 정본의 대체물이 아니다.
- **`R1-3-7-b`** — 매 독해 직후 1~2줄: 경로 · `offset`/`limit` · 도착 여부 · **그 구간 고유 토큰 2~3개**
  (작업 끝에 몰아 쓰지 마라 — 이미 트리밍됐다).
- **`R1-3-7-c`** — 인용 판정은 `read` → **원문 구절 + 좌표를 파일에 기록** → 판정 순. 못 썼으면 판정하지 않는다.
  삭제보다 취소선이 안전하다.

### Step 2. 브리핑 완료 대기 → `00_BRIEF.md` 만 읽는다

「5문서 전량 독해」는 폐지됐다(`R1-1` 소관 · 경위 = `91_사고사례집.md` §C13). 세션 시작 독해는 브리핑 1개다.

`bash_output` 에 Step 0 의 shell id 와 `wait=true` · `timeout_ms=300000` 을 넘긴다.
- 🔴 **`BRIEF_RC=0` 을 본 뒤에만** 다음으로 간다(`R0-8`) — 그 전의 `00_BRIEF.md` 는 **직전 세션 것**이다.
- 아직 실행 중이면 같은 호출로 다시 기다린다(재실행 금지 — 두 프로세스가 같은 파일을 쓴다 · `R1-7-2`).
- `rc≠0` 이면 `/tmp/session_brief.out` 을 `read` 하고 브리핑에 FAIL 로 적은 뒤 사용자 지시를 기다린다.

🔴 손으로 고치지 마라(재생성에서 사라진다). 🔴 **「열림」은 상태가 아니라 기재다** — 착수 전 실측(§3 J3).

### Step 3. 브리핑 출력

게이트는 `session_brief.py` 가 이미 돌렸다(`00_BRIEF.md` §6) ⇒ 따로 돌리지 않는다.
🔴 게이트 목록의 정본 = `scripts/session_brief.py` 의 `GATES`(문서와 다르면 **코드를 믿어라** · `R3-9 ㉦`).
🔴 FAIL 이면 브리핑에 그대로 적고 사용자 지시를 기다린다(임의 재균형·은퇴 금지). 🟠 경고는 보고만.

단답형으로 **아래만** 출력한다. 수치는 `00_BRIEF.md` 에서 **그대로 옮긴다**(세지 마라 · 창작 금지).

```
지침 로드: OK
게이트: 유형 <판정> · 조문순서 <판정> · 행키 <판정> · 제목 <판정> · 좌표 <판정> · Jinja <판정> · 조각수 stale <n>
열린 작업: <착수표 열린 건수> — <순번 3개 이내>
직전 세션 인수인계: <현행 §절 라벨> — <1줄>
문서50 열린 절: <건수>
read 미반환: <건수> · 재호출 <건수>   ← 0 이면 「0」이라고 적는다
다음 후보 작업: <1~3개>
대기 중
```

**⚠️ 조건부 STOP**(정본 = 지침 `R4-4`)

- **㉠ 지시가 없는 턴** = 브리핑 출력 후 **STOP**.
- **㉡ 지시가 같은 턴에 있으면** = **브리핑을 먼저 출력한 뒤 즉시 수행**한다
  (「브리핑 없이 착수」와 「지시가 있는데 되묻기」를 둘 다 막는다).
- 🔴 **`R4-4-3` 파괴 가능 작업**(discard · `rm` · `ALTER WORKSPACE … ABORT` · `--rebalance`·`retire_rows`
  같은 다중 파일 재작성 · 과금이 큰 LLM 대량 호출)은 **지시가 있어도 별도 승인** — ㉡ 보다 강하다.
  `증분형` 문서(문서20·문서50)의 `--rebalance` 는 도구가 거부한다 — 대체는 `--rollover` ·
  🔴 `--force-rebalance` 로 뚫지 마라. 🔴 가드를 심었으면 **거부되는지 실증**하라.
- 🔴 **어느 경우든 브리핑 미출력은 위반이다**(`A5`).
- 🟠 ㉡ 로 진행한 세션은 이력에 「㉡ 적용」과 확정위반 건수를 함께 적는다(롤백 판단 근거).

| J2 | 「없다」 전에 **내가 본 그릇이 그 값을 담는 그릇인가** → 저장 위치(키·구분자·레벨)를 한 번 덤프한 뒤 센다 |
| J3 | 「열려 있다」는 상태가 아니라 **기재**다 → 착수 전 3줄 실측: ㉠ 객체·파일 실재 ㉡ 수치 재측정 ㉢ 타 세션 집행 여부(라벨 grep) · 「현업 소관」도 실측으로 판정 |
| J4 | 선행조건이 「전량 독해」면 → **문서 크기를 다시 재라**(분할이 선행조건을 없앤다) |
| J5 | 예약 조치(「조건 충족 시 X」)를 폐기했으면 → **그 문장을 grep 으로 전수 찾아 표시** |
| J6 | 「함수 부재」 ≠ 「기능 차단」 → `SHOW FUNCTIONS` 로 실재를 먼저 확인한 뒤 호출 오류를 읽는다 |
| J7 | 과금 축 ≠ 컨텍스트 축 → 대량 호출은 원문을 파일로 흘리고 요약만 출력 · 과금 도구는 `gate_census.MUTATES` 승인 대상 |
| J8 | 자기참조 계측 → 자기 편집이 바꾸는 값은 문서에 적지 말고 게이트로 읽는다 · 부정문은 **정확한 토큰**으로 재판정 · 도구는 대상을 **게이트의 판정 함수**에서 받는다 |
