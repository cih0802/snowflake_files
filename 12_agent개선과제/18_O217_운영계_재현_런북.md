## 3. 운영계 spec 이 개발계와 다를 때 (② 불일치)

🔴 개발계 yaml 을 그대로 덮어쓰지 않는다 — 운영계에만 있는 지침·도구가 사라진다(spec 은 전체 교체다).

1. 운영계 export 파일을 `15_O217_백업_AGENT_<X>_spec.yaml` 자리에 **다른 이름으로** 두고 생성기 입력 경로를 바꾼다.
2. 생성기를 순서대로 다시 돌린다(치환 대상이 없으면 실패하도록 돼 있다 — 조용히 무변경되지 않는다):
   - `tools/o217_patch_marketing_spec.py` → `17_O217_AGENT_MARKETING_spec.yaml`
   - `tools/o217_patch_search_tool.py` → `17_O217_AGENT_MEMBER·EXECUTIVE_spec.yaml`
   - `tools/o217b_patch_inc_campaign.py` → `19_O217B_AGENT_MARKETING_spec.yaml`
3. 생성기가 「치환 대상 없음」으로 멈추면 그 문단이 운영계에서 이미 바뀐 것이다 — 원문을 대조해 정규식을 고친다.
4. 결과를 `diff` 로 운영계 export 와 비교해 **orchestration·system·response·tools·tool_resources 외 키가 바뀌지 않았는지** 본다.
