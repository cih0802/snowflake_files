# 회원 LTV 기대 유지개월 — 상한별 비교 (🟠 잠정 정의 · 현업 확인 요청)

> 개발계(jw08094) 실측 · 2026-10-15 · 전체 표 = `O231_LTV_현업비교표.csv`(72행 · 전체 1 + 개발인입경로 13 + 캠페인카테고리 58)
> **요청 사항: 아래 ①~④ 중 어떤 기준으로 확정할지 회신 부탁드립니다.** 회신 전까지 Agent 의 LTV 답변(RT-14·RT-27)은 바꾸지 않습니다.

## 1. 무엇이 문제였나

현재 LTV 산식 = 평균 월 회비 × **평균 유지개월**이고, 평균 유지개월은 **중단한 회원만**의 평균입니다(`AVG_TENURE_DAYS`).
아직 후원 중인 회원이 빠지므로, 최근 가입자일수록 짧은 기간 안에 중단한 사람만 남아 값이 크게 작아집니다.

| 기준 | 전체 회원 유지개월 |
|---|---|
| 현행 · 최근 24개월 가입자 | **5.5개월** |
| 현행 · 전체 이력 | 38.9개월 (상한 없음 · 오래 유지하다 중단한 회원만 반영) |
| 생존분석 · 상한 36개월 | **27.4개월** |
| 생존분석 · 상한 60개월 | **40.7개월** |

⇒ 같은 회원 집단이 기준에 따라 5.5 ~ 40.7개월로 달라집니다. 「현행」은 어느 쪽이든 후원 중인 회원을 빼고 계산한 값이라 LTV 로 쓰기에 부적합합니다.

## 2. 새 기준(생존분석)이 하는 일

- 가입 후 경과월마다 「그 달까지 남아 있던 회원 중 몇 %가 중단했는가」를 계산해 **유지 곡선**을 만듭니다(Kaplan–Meier).
- 아직 후원 중인 회원도 **관측된 기간만큼** 포함합니다(중단하지 않았다고 해서 빼지 않습니다).
- **기대 유지개월(상한 N개월)** = 가입 후 N개월 안에서 평균적으로 몇 개월 유지하는가(유지 곡선 아래 면적).
  - 상한을 두는 이유: 데이터 기간 밖의 미래 유지는 추정이 불안정하므로, 확인 가능한 범위까지만 셉니다.
  - 상한이 길수록 값이 커지는 것은 정상입니다(더 긴 기간을 셀 수 있으므로).

| 개발인입경로 | 현행 기준 | 상한 36 기준 | 상한 60 기준 |
|---|---|---|---|
| 콜개발 | 2.1억 원 | **8.5억 원** | 12.8억 원 |
| 방송 | 1.9억 원 | 6.8억 원 | 10.1억 원 |
| 디지털 | 1.3억 원 | 6.1억 원 | 9.0억 원 |

- **순위가 바뀌는 경우가 있습니다**: 예) ‘기타 기업개발’은 현행 4.2개월(하위권)이지만 상한 36 기준 33.7개월(최상위권)입니다 — 최근 가입자 중 짧게 중단한 일부만 현행 값에 잡혔기 때문입니다.
- 이 금액은 광고비·모집비용을 빼지 않은 **기대 회비 총액**입니다(모집단가 대비 판단은 별도).

## 5. 산출 기준(참고)

- 대상 = 획득(최초 개발) 회원 1,621,050명(FACT_MEMBER_COHORT) · 획득일이 무효인 20명 제외 · 관측 기준일 2026-10-13.
- 유지개월 = 경과일 ÷ 30.44(내림) · 생존분석 축 = **가입 후 경과월**(달력월 아님).
- 기대 유지개월(상한 τ) = Σ_{m=0}^{τ−1} P(유지 ≥ m) — 표준 제한평균(RMST). 
  - O230 진단 문서의 28.0 / 41.2개월은 같은 데이터에 항이 하나 더 들어간 식(1 + Σ_{t<τ} S(t))이라 0.5~0.6개월 큽니다 — 표준식으로 정정했습니다(사용자 결정 O231).
- 셀 = 획득 시점 개발인입경로 · 캠페인카테고리(원천 NULL = ‘(미상)’).
- 반영 위치(개발계): `GOLD.FACT_MEMBER_COHORT`(OBS_TENURE_*·IS_STOPPED_OBS) · `GOLD.FACT_MEMBER_COHORT_SURVIVAL`(O232 · 생존 곡선 테이블) · `SERVING.SV_MEMBER_COHORT`(EXP_TENURE_MONTHS × 상한 차원) · 설정 = dbt vars `ltv_caps`·`ltv_learn_start`·`ltv_min_cell`(상한을 바꿔도 컬럼은 그대로).
