# [회신] 마케팅 분석 Agent 3차 피드백 답변

안녕하세요, 데이터팀입니다. 3차 피드백으로 주신 질문에 답변드립니다.
아래 「화면에서는」 부분은 **Snowflake Intelligence 채팅 화면**에서 실제로 보이는 이름과 표 제목 그대로 적었습니다.

---

## 먼저 — 화면에서 고를 Agent

채팅 화면 왼쪽 위에서 Agent 를 고릅니다. 이름과 색이 아래처럼 보입니다.

| 화면에 보이는 이름 | 이럴 때 고르세요 |
|---|---|
| 🟠 **마케팅 분석** | 광고비 · 캠페인별 성과 · 제작비 · 개발단가 · 홈페이지 방문 · 검색어 |
| 🔵 **경영·전사 분석** | 예산 편성·집행 · 사업목표 · 회원 월실적 · 지출결의 |
| 🔷 **회원 분석** | 회원 · 회비 · 캠페인별 회원 · 발송 · 행사 참여 |

> 📌 **이번에 바뀐 점** — 광고비와 광고 성과는 이제 **「마케팅 분석」에서만** 조회합니다.
> 「경영·전사 분석」에 광고비를 물으면 「광고 지표는 마케팅 분석 Agent 소관입니다」라고 안내합니다.
> 질문에 광고 말고 다른 내용(예산·회원 실적 등)이 섞여 있으면 그 부분은 그대로 답합니다.

---

## Q1. 광고비가 매체마다 기준이 달라 합계가 안 맞습니다. 최종 광고비를 한 숫자로 볼 수 있나요?

**네, 「최종 광고비」를 새로 만들었습니다.** 정해 주신 기준대로 매체별 금액을 더합니다.

| 매체 | 더하는 금액(원천 화면의 이름) |
|---|---|
| 디지털 | 최종정산금액 (광고비 + 마크업 + 부가세) |
| 영상 | 최종광고비 |
| 방송 | 총비용 (편성비 + 콘텐츠구입비 + 콜센터운영비) |

- **이렇게 물어보세요** — 「2026년 마케팅캠페인별 월 **최종 광고비** 보여줘」
- **화면에서는** — 표에 `마케팅캠페인명` · `연월` · `최종 광고비` 열이 나옵니다. 매체별로 보려면 「매체별로 나눠서」라고 덧붙이세요(`디지털 최종정산금액` · `영상 광고비` · `방송 총비용`).
- **맞는지 확인했습니다** — 운영 환경에서 최종 광고비 합계를 매체별 원장과 대조해 원 단위까지 일치했습니다.
- ⚠️ 그냥 「광고비」라고 물으면 마크업·부가세를 뺀 **대행사 광고비**가 나옵니다. 정산 기준 금액이 필요하면 꼭 「**최종** 광고비」라고 적어 주세요.

## Q2. 제작비는 어떤 기준으로 잡히나요?

**지출결의 중 「콘텐츠구분자(세부캠페인코드)」가 적힌 건 전체**를 그 캠페인의 제작비로 봅니다(확정해 주신 규칙).

- **이렇게 물어보세요** — 「마케팅캠페인별 **제작비** 보여줘」
- **화면에서는** — `마케팅캠페인명` · `제작비` 열이 나옵니다. 제작비의 월은 **결의 작성일** 기준입니다.
- ⚠️ 콘텐츠구분자가 비어 있거나 「-」인 지출은 어느 캠페인 것인지 알 수 없어 빠집니다.
  제작비가 생각보다 작으면 지출결의에 구분자가 적혀 있는지 먼저 확인해 주세요.
- ⚠️ 지출결의는 매번 전체를 다시 불러옵니다. 그래서 과거 결의의 구분자를 고치면 **과거 달 제작비도 함께 바뀝니다**.

## Q3. 캠페인별 광고비 · 개발건수 · 제작비를 한 표로 볼 수 있나요?

**네, 한 번 질문하면 한 표로 나옵니다.**

- **이렇게 물어보세요** — 「2026년 마케팅캠페인별 최종 광고비, 개발건수, 제작비, 개발단가를 한 표로」
- **화면에서는** — `마케팅캠페인명` · `최종 광고비` · `CRM 기반 개발(건)` · `제작비` · `CRM 개발단가` 열이 나옵니다.

| 화면 열 이름 | 뜻(지표사전) |
|---|---|
| `CRM 기반 개발(건)` | CRM 후원금액 ÷ 10,000 (신규·증액·재후원). **이 표의 기본 개발건수**이고, 답변에 「CRM 기반 개발건수」라고 밝힙니다. 소수점이 나올 수 있습니다. |
| `CRM 개발단가` | 최종 광고비 ÷ CRM 개발(건) |
| `MSTR 개발(건)` · `MSTR 개발단가` | 질문에 「**MSTR 기준으로**」라고 적을 때만 나옵니다. |
| `제작비 포함 개발단가` | (광고비 + 제작비) ÷ MSTR 개발(건). 제작비가 구분자 기재분만이라 실제보다 작게 나올 수 있습니다. |

- `마케팅캠페인명`이 **「(미매핑)」**인 줄은 어느 캠페인에도 연결되지 않은 금액입니다. 전체 합계를 맞추려고 빼지 않고 그대로 보여 드립니다.
- 이 표에는 **마케팅채널·인입경로별 비용이 없습니다.** 캠페인 하나에 채널이 여러 개라 대표값을 나눠 붙이면 숫자가 틀려지기 때문입니다.
- 📖 Q1~Q3 의 지표 7가지(최종 광고비 · 디지털 최종정산금액 · 방송 총비용 · 제작비 · CRM 기반 개발(건) · CRM 개발단가 · 제작비 포함 개발단가)는 **지표사전에도 올렸습니다.** 「최종 광고비가 뭐야?」처럼 뜻·계산식을 물으면 위 정의 그대로 답합니다.

## Q4. 출처 표기가 「재방송」으로 나옵니다.

**「방송」으로 바꿨습니다.** 매체를 나눠 보여 줄 때 `방송`으로 표시합니다.

## Q5. 일부 월의 제작비가 갑자기 변했습니다. 원인이 뭔가요?

**아직 확인 중입니다.** Q2 의 ⚠️ 두 번째 항목(과거 결의 구분자 수정)이 원인일 가능성이 있어, 운영 원천 데이터 조회를 요청해 두었습니다. 결과가 나오면 따로 알려 드리겠습니다.

## Q6. 영상 광고의 개발실적과 마감값이 맞지 않습니다.

**원천 확인이 필요해서** 데이터 담당 부서에 확인을 요청했습니다. 그때까지 Agent 는 이 항목을 「원천 확인 필요」라고 안내합니다.

## Q7. 방송 총비용이 9·10월에 비어 있습니다.

**원천에 값이 아직 입력되지 않은 상태입니다.**

- 이런 달은 최종 광고비에서 방송분이 빠집니다. 그래서 Agent 가 답변에 「**일부 원천 값 미입력 · 하한값**」(실제보다 작을 수 있음)이라고 함께 적습니다.
- 방송 총비용을 입력해 주시면 **다음 날 자동으로** 반영됩니다.
