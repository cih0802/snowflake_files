# 분석 Agent 이용 안내 (O209 · 2026-10-07 · 개발계 기준)

> 어느 Agent 에 물을지 모르면 「분석 Agent 안내」에 먼저 물어보세요.
> 안내 Agent 는 수치를 답하지 않고, 물어볼 Agent 와 다듬은 질문을 알려 줍니다.

## 1. 한 줄 원칙

질문에 나온 **축**(캠페인·채널·부서·후원사업)이 아니라 **구하려는 값**이 Agent 를 정합니다.

| 구하려는 값 | 물어볼 Agent |
|---|---|
| 개발(건·명·금액)·회비의 실적 집계 · 목표 대비 달성 · 연도말 전망 · 예측 · 회원실/기획실 집계 · 예산 | **경영·전사 분석** |
| 이미 가입한 회원의 특성 · 중단/증액/정기전환 가능성(회원 단위) · 이탈률 · 서비스 발송 효과 · 행사 · 결연 | **회원 분석** |
| 광고비·광고 효율·개발단가 · 웹사이트 방문 행동(GA) · LTV · 신규 획득 타겟 | **마케팅 분석** |

## 2. 자주 헷갈리는 질문

| 질문 예 | 물어볼 Agent | 이유 |
|---|---|---|
| 캠페인카테고리별 신규 개발 건수 | 경영·전사 분석 | 캠페인 축이지만 구하는 값은 개발 실적 |
| 다음 달·연말 신규 개발 전망 | 경영·전사 분석 | 개발 예측 · 연도말은 MSTR 추세 참고치 |
| 캠페인카테고리별 향후 회비 전망 | 경영·전사 분석 | 회비 예측 |
| 일시 후원자 중 정기 전환 가능성이 높은 회원 | 회원 분석 | 대상이 회원 개인 |
| 증액 캠페인을 제안할 회원 | 회원 분석 | 대상이 회원 개인 |
| 캠페인별 12개월 이탈률 | 회원 분석 | 획득 코호트 |
| 채널별 LTV · 이탈 위험이 높은 웹 페이지 | 마케팅 분석 | LTV · GA 행동 |

## 3. 답변을 읽을 때

- 표 제목의 **「MSTR 기준」/「GN_DW 기준」**은 서로 다른 기준입니다. 두 수치를 더하거나 비교하지 마세요.
- 「추세 참고치」는 모델 예측이 아니라 최근 실적 평균으로 계산한 값입니다.
- 머신러닝 예측은 테스트 단계라 값이 바뀔 수 있습니다.
- 정해진 산식이 없는 지표(추경·시나리오·최적 배분·임계점 등)는 Agent 가 계산 전에 가정을 확인합니다.
- 「신규 개발」은 기본적으로 개발구분 = 신규로 계산합니다. 신규/기존 구분이 필요하면 「신규기존구분으로」라고 적어 주세요.

## 4. 바뀐 점(O209)

- 회원실·기획실 집계(회비예측·후원 분류 집계·연간 개발 목표)와 개발 목표 달성·월 KPI 를 **경영·전사 분석**에서도 조회할 수 있습니다. 회원 분석에서도 당분간 그대로 조회됩니다.
- Agent 이름은 바뀌지 않았습니다.
