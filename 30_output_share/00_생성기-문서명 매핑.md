# 30_output_share 산출물 및 생성기 매핑 가이드

> 본 문서는 `30_output_share/` 폴더 내에 배포되는 DW 현업 공유 산출물과 이를 자동 생성·재현하는 스크립트(`scripts/gen_*.py`) 간의 매핑 및 실행 방법을 정리한 정본 가이드입니다.

---

## 1. 개요 및 산출물 분류

`30_output_share/` 폴더의 문서 및 산출물은 크게 **(1) 스크립트를 통한 자동 생성 산출물**과 **(2) 도메인 분석·의사결정 수기 정본**으로 구분됩니다.

* **자동 생성 산출물**: dbt 모델 메타데이터, Snowflake Live 카탈로그/Census, 또는 업스트림 산출물을 파싱하여 100% 코드로 재현 가능한 산출물입니다.
* **수기 분석 문서**: 비즈니스 정책 검토, 원천 결손 분석, 미해결 이슈 해결을 위한 의사결정 기록 및 수기 쿼리입니다.

## 3. 골든 회귀 테스트 및 검증 체계

산출물 중 핵심 5종(`04`, `05`, `06`, `08`, `09`)은 회귀 테스트 체계가 구축되어 있습니다.

* **테스트 스크립트**: `scripts/test_generators.py`
* **검증 내용**:
  * **골든 대조(G)**: `scripts/golden/outputs.json` 대비 행수 및 판정 분포 불변성 검증
  * **순서 독립성(T1)**: 입력 데이터 순서가 변경되어도 판정 결과가 동일한지 검증
  * **라벨 사전 오염 방지(T2)**: 수기 문서 수정 시 불필요한 마커가 사전에 유입되지 않는지 검사
  * **문자열 계약(T3)**: 생성기 간 상호 참조 문자열 일치 여부 대조
  * **근거 식별자 강제(T4)**: 결손·불가 판정 시 실제 DB 식별자(백틱 표기) 포함 여부 검증
* **실행 명령**:
  ```bash
  python3 scripts/test_generators.py
  ```

## 4. 재생성 시 실행 순서 (파이프라인 의존성)

산출물 간 상호 참조 관계가 있으므로 전체 재생성 시 다음 순서로 실행해야 합니다:

```bash
# 1단계: 메타데이터 인벤토리·계보 및 코드체계 기초 산출물 생성
python3 scripts/gen_column_inventory_20260811.py $(date +%Y%m%d) # 02 생성
python3 scripts/gen_column_mapping.py                           # 04 생성
python3 scripts/run_bronze_audit_host.py                         # 06 생성
python3 scripts/gen_code_system_gates.py                         # 07 생성
python3 scripts/gen_silver_gold_retention.py                     # 08 생성

# 2단계: 04 산출물을 입력으로 사용하는 지표 매핑 생성
python3 scripts/gen_metric_gold_mapping.py   # 05 생성 (04 참조)

# 3단계: 04·05 산출물을 조합하는 보고서 조립가능성 생성
python3 scripts/gen_section_assembly.py      # 09 생성 (04, 05 참조)

# 4단계: 이슈 요약 및 시각화 산출물 생성
python3 scripts/gen_unresolved_issue_summary.py --write # 11 생성
python3 scripts/gen_concept_diagram.py                  # 03 생성
python3 scripts/gen_arch_map.py                         # 아키텍처 지도 생성
python3 scripts/gen_gold_erd.py                         # GOLD ERD 생성
python3 scripts/gen_pipeline_erd.py                     # 파이프라인 ERD 생성

# 5단계: 회귀 테스트 검증
python3 scripts/test_generators.py
```
