# GN_DW 데이터 활용 가이드 (표준 지표 · 사용 가능 범위 · 오독 방지)

> GN_DW 데이터 웨어하우스의 **현업 활용 가이드** — 기술 개념도(`03_GN_DW_개념도.html`)와 함께 보는
> 현업(CRM·마케팅·재무) 대상 단일 자료입니다.
> 관점: **"어떤 업무 질문에 답할 수 있는가"** · **"그 숫자를 믿어도 되는가"**
>
> 🔴 **이 판본의 모든 상태·수치는 2026-08-06 실측입니다.** 컬럼 COMMENT 나 설계 문서를 근거로
> "사용 가능"이라고 적은 항목은 없습니다 — 각 지표에 대응하는 물리 컬럼에 직접 집계를 돌려 확인했습니다.

## 0. 먼저 읽을 것 — 조용히 틀리는 지표 5종

> 아래 다섯 개는 **에러도 경고도 없이 그럴싸한 값을 반환**합니다. 그래서 지금까지 실제로 잘못 인용됐습니다.
> 다른 어떤 절보다 먼저 읽어 주세요.

| # | 무엇을 물으면 | 잘못된 값 | 정본 값 | 왜 틀리나 |
|---|---|---|---|---|
| 1 | **개발(명)** | `SUM(DEV_MEMBERS)` = **2,291,878** | **1,585,923** | `*_MEMBERS` 는 「명」이 아니라 **사건 플래그(0/1)** 입니다. 합하면 사건 수가 나오고 **44.5% 과대**입니다. 「명」은 `COUNT(DISTINCT 회원)` 입니다 |
| 2 | **발송 회원수** | 38,470,780 | **1,031,971** | 앞은 발송 **건수**(행 수)입니다. 고유 회원은 **37.3배** 적습니다 |
| 3 | **납부율** | `PAYMENT_RATE` (기부금 혼입) | **86.19%** (`PAYMENT_RATE_FEE`) | 분자에 기부금이 섞이고 분모는 회비 청구만이라 **모집단이 다릅니다**. 전 기간으로 돌리면 100% 를 넘던 지표입니다 |
| 4 | **총미납금액** | `TOTAL_UNPAID_AMT` (차감식) | **1,226억 원** (`TOTAL_UNPAID_AMT_DEC3`) | 「청구−납입」 차감식이라 **기부금이 미납을 상쇄**합니다. 전 기간으로 돌리면 음수가 나왔습니다 |
| 5 | **목표 달성율** | 실적 ÷ 목표를 직접 나눔 | `ACHIEVEMENT_RATE` 지표 사용 | 목표가 편성되지 않은 부서·월의 실적이 분자에 섞여 **과대**해집니다 |

**공통 대응**: 위 지표는 **Agent(Snowflake Intelligence)에 자연어로 물으면 정본 지표로 라우팅**됩니다.
직접 SQL 로 `SUM()` 을 돌리기 전에 이 표를 확인하세요.

> 🔴 **`0` 을 실적으로 읽지 마세요.** GOLD 에는 「컬럼 자리는 있으나 값이 아직 안 들어온」 컬럼이
> **98개** 있습니다(전건 `0` 또는 `NULL`). 조회하면 에러 없이 `0` 이 나옵니다.
> 전량 목록 = `05_지표GOLD매핑.md` §0-2 · `04_컬럼계보매핑.md` §3.

## 2. 핵심 지표 표준화 정의서 (Standard KPI Glossary)

> Silver·Gold 계층의 목적 = **부서 간 지표 표준화(Single Source of Truth)**.
> 아래 정의는 배포된 GOLD 컬럼 COMMENT 와 SV metric 정의를 근거로 하며, **실측 상태를 병기**합니다.

### 2-1. ✅ 지금 쓸 수 있는 지표

| 표준 지표 | 정의 / 산출 기준 | 위치 | 실측 |

| **납입회비(원) `PAID_FEE_BILLABLE`** | 회비 청구에 대응하는 납입액(기부금 제외) | `FACT_MEMBER_MONTHLY` | 전 기간 **768,800,286,349** |

> `GENDER` → **`SEX`**. 저장된 쿼리·대시보드가 구 컬럼명을 쓰고 있으면 갱신이 필요합니다.

### 2-3. 🔴 값은 있으나 의미를 오해하기 쉬운 지표

| 지표 | 오해 | 사실 |
|---|---|---|
| `*_MEMBERS` (`DEV_MEMBERS`·`STOP_MEMBERS`·`SEND_MEMBERS`) | 「명」 | **사건 플래그(0/1)**. `SUM` 은 건수. 「명」은 `COUNT(DISTINCT 회원)` |
| `MEMBER_REGION`·`MEMBER_AGE_BAND` | 현재 거주지·현재 연령 | **약정(개발) 시점 스냅샷**. 현재 값은 **산출 불가**(BRONZE 에 생년월일·현주소 축이 없음) |
| `AGE_BAND` 최다 구간이 `10대 미만` | 데이터 오류 | **실제입니다.** 편지쓰기대회 계열 캠페인(희망편지·가족그림편지·세계시민교육편지)이 아동 본인 명의로 약정을 맺습니다 |
| `_AT_EVENT` vs `_AT_PLEDGE` | 같은 축 | **다른 축**. `_AT_EVENT` = 그 사건 당시 값(정확) · `_AT_PLEDGE` = 최근 약정 스냅샷 |
| `DVLP_DIV_NM = '후원중단'` 행 | 중단 실적 | `EVENT_TYPE='STOP'` 행과 **동일 사건**입니다 → 합산 금지 |
| `REASON_TYPE` | "중단/미납 구분" | 실제값은 **CRM 코드그룹 ID 336종**입니다 |
| 미납 금액·비중 | 확정치 | **조회 시점 스냅샷**입니다. 과거 연도 미납이 이후에 납입되면 값이 바뀝니다 |
| `(미매핑)` 버킷 | 결측 | 차원 미매칭을 담는 **Unknown 멤버(`SK=0`)** 입니다. 이 버킷이 큰 축은 분해 결과가 부분집합입니다 |

## 4. 비즈니스 도메인 관계도 (Domain Model)

> 시스템 키·이력관리 방식 등 구현 요소를 배제하고 업무 언어로 표현한 관계 조망.

```
                       ┌──────────────────┐        ┌────────────┐
          ──가입──▶     │  캠페인 / 브랜드  │ ──귀속──▶ │ 조직 / 부서 │◀──목표편성──
          │            └──────────────────┘        └────────────┘
  ┌──────────────┐              │
  │ 회원 / 후원자 │       ──코호트──┘   (획득 시점 특성 · 12개월 이탈률)
  └──────────────┘
          │
          ├──참여──▶  [ 행사 · 서신 · 발송(알림톡·메일·서신) ]
          │
          └──결제──▶  [ 납입 · 청구 · 미납 ]        [ 예산(편성/집행) ]
                                                    [ 광고(디지털·방송) ]
```

- **중심 축**: `회원/후원자` ──가입──▶ `캠페인/브랜드` ──귀속──▶ `조직/부서`
- **코호트 축**: `회원/후원자` 를 **획득 시점 기준 1행**으로 고정 → 캠페인별 이탈률·유지기간
- **목표 축**: `조직/부서` × 월 × 개발구분 으로 목표를 편성 → 실적과 월 단위로 대응
- **활동 축**: `회원/후원자` ──참여──▶ `행사/서신/발송`
- **재무 축**: `회원/후원자` ──결제──▶ `납입/청구/미납` · 별도로 `예산`·`광고비`

> ⚠️ **예산(ERP)과 광고비(대행사)는 서로 다른 원천 시스템**입니다. 한 표에서 교차 집계하지 마세요.
