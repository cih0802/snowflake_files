# 일시후원 전환 예측 — 다중 예측행 확인 요청 (1건)

- 수신: **ML 담당**(현업 아님)
- 현재 조치: `SV_ML_ONCE_CONVERSION` 에 「회원당 다중 예측행 · 회원수는 중복제거로」 경고를 달아 둠.

## 여쭙는 것

1. 같은 관측월에 한 회원이 여러 예측행을 가집니다. 이 행들은 무엇입니까?
   ⓐ 모델 버전별 행 ⓑ 재실행 누적 ⓒ 기타
2. **현재 예측을 가리는 컬럼**(버전 · 실행 순번 · 실행 시각)을 추가할 수 있습니까?
- DW 추천: ⓐ 또는 ⓑ + 순번 컬럼.

## 🆕 [O191-C] 결정 · ML 담당 요청 (1건)

- 현업 결정(45) = **재실행 누적이면 최신만 남기고 실행순번 컬럼 추가**.
- 📏 DW 실측 = 같은 회원·관측월에 **2~6개의 서로 다른 예측행**(DATA_TYPE 은 전부 SCORE) ·
  원천 `ML_RST_DATA_ONCE_CONVERSION` 에 **실행 시각·순번 컬럼이 없다** ⇒ DW 가 「최신」을 고를 수 없다(임의 선택 = 창작).
- 🔴 **요청**: 결과 적재 시 `RUN_SEQ`(실행 순번 · 정수 증가) 또는 `RUN_TS`(실행 시각) 컬럼 1개를 추가해 주십시오.
  들어오면 DW 가 SERVING 뷰에서 회원·관측월별 최신 1행만 남깁니다(추가 회신 불요).
