# 01_문서분할_규약_조각 — 문서분할 규약 조각 보관소

> 목적 = `00_guides/01_문서분할_규약.md` 허브 문서가 분할 기준을 초과하여 분리된 실제 조각 본문 파일들과 조각 선택표를 보관한다.
> 파일 목록 = 같은 폴더 `00_FOLDER_INDEX.md`(자동 생성 · 손으로 고치지 않는다).

## 구성

| 하위 폴더·파일 묶음 | 내용 |
|---|---|
| `00_선택표.md` | 조각별 수록 범위 및 절/ID 색인 선택표 (자동 생성물) |

## 참고

- 상위 가이드인 `00_guides/01_문서분할_규약.md`가 허브 역할을 하며, 본문 열람 시 `00_선택표.md`를 통해 대상 조각을 탐색한다.
- 조각 파일은 `scripts/split_doc.py` 도구에 의해 관리되므로 임의로 직접 분할/합병하지 않는다.
