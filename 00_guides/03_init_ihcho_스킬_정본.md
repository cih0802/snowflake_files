## ▣ 1. 이 스킬은 무엇인가

| 축 | 내용 |
|---|---|
| **이름** | `init_ihcho` (user 스킬 · 이 워크스페이스 전용) |
| **한 줄 정의** | 세션 최초 턴에 **작업 지침을 로드하고 · 열린 작업을 브리핑으로 확보하고 · 읽기/쓰기/셸 가드를 활성화**하는 초기화 스킬 |
| **왜 필요한가** | 이 워크스페이스는 문서군이 **270만 자**를 넘어 전량 독해가 물리적으로 불가능하다. 그래서 「무엇을 읽어야 하는가」를 **스크립트가 정하고**, 세션은 그 산출물만 읽는다. 가드가 없으면 매 세션 같은 사고(원장 파괴 · 줄 절단 · 0건 오판)를 반복한다 |
| **호출 시점** | 세션 **최초 턴 1회**. 같은 세션에서 재호출하지 않는다(이미 로드된 상태) |
| **산출** | 지침 + `20_issue/00_BRIEF.md` 컨텍스트 + **단답형 브리핑** + (지시 동봉 시) 즉시 착수 |
| **정지점** | 지시가 없으면 브리핑 후 STOP · **파괴 가능 작업은 지시가 있어도 별도 승인**(`R4-4-3`) |

### 1-1. 트리거 설계

`description` 은 스킬 발동의 **유일한 기전**이다. 이 스킬은 **과소발동(undertriggering)이 치명적**이다 —
발동하지 않으면 가드 없이 세션이 시작되고, 그 세션의 모든 쓰기가 위험해진다.
⇒ 트리거에 `init_ihcho` 같은 명시 호출뿐 아니라 **`세션 시작`·`작업 시작`·`초기화`·`이어서 작업`·`인수인계`**
같은 자연어를 전부 넣는다.

### 1-2. 이 스킬이 **하지 않는** 것

| 하지 않는 것 | 왜 |
|---|---|
| 문서 5종 전량 독해 | 물리적 불가 ⇒ O106 이 폐지. 대신 `session_brief.py` 산출물 1개를 읽는다 |
| dbt 실행(`build`/`run`/`test`/`compile`/`parse`) | **사용자 소관 정지점**. 에이전트는 명령문 작성·결과 해석까지만 |
| 게이트 개별 실행 | Step 2 의 `session_brief.py` 가 이미 돌린다(`--no-gates` 일 때만 손으로) |
| 사례집(`91`)·규약 정본 독해 | **사고를 조사할 때** 읽는다. 세션 시작에는 읽지 않는다 |

### 5-1. 압축·개정 후 토큰 보존 대조 (필수)

🔴 **본문을 줄이거나 재배치했으면 아래를 돌려 차집합이 「계약이 아닌 것」뿐인지 눈으로 판정한다.**

miss=[x for x in sorted(set(RX.findall(old))) if x not in set(RX.findall(new))]
print('누락', len(miss), miss)
