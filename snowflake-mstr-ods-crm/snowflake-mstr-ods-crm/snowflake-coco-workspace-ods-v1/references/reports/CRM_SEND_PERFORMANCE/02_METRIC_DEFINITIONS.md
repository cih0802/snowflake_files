# CRM 발송성과 지표 정의

아래 정의는 구조상 후보와 확정 대상을 구분한다. 업무 담당자가 확정하지 않은 값은 CoCo가 임의로 선택하지 않는다.

| 지표 | 업무 의미 | 현재 상태 | 확인할 기준 |
|---|---|---|---|
| 발송 수 | 발송 대상 또는 실제 발송 시도 규모 | 미확정 | 대상 수/시도 수/고유 수신자 중 선택 |
| 발송 성공 수 | 최종적으로 전송 또는 도달에 성공한 규모 | 미확정 | 성공 상태, 재시도 최종행, 고유 수신자 여부 |
| 클릭율(GA) | 발송 후 클릭 반응 비율 | GA 근거 미확인 | 분자, 분모, GA 추적키 존재 여부 |
| 서신 참여 수 | 인정기간 안에 서신에 참여한 고유 회원 | 미확정 | 작성/접수/완료 중 인정 상태 |
| 선물금 참여 수 | 인정된 선물금에 참여한 고유 회원 | 미확정 | 승인/납입/접수 상태, 취소·환불 제외 |
| 선물금 참여 건 | 인정된 고유 선물금 업무 건 | 키 후보 확인 | 상태와 전체 업무키 확인 |
| 중단 회원 수 | 인정기간 안에 후원을 중단한 고유 회원 | 미확정 | 발송과의 귀속, 회원 중복 제거 |
| 중단 회원 건 | 인정된 고유 후원/관계 중단 건 | 미확정 | 중단 업무 Grain, 상태변경 로그 제외 |

## 클릭률 주의

`SND_MEMBER_MAIL_LINK_LOG`는 발송 시스템의 메일 링크 클릭 이벤트다. 승인된 50개 원천 안에서 Google Analytics 이벤트 또는 GA 캠페인·콘텐츠 추적 매핑이 확인되지 않으면 다음 중 하나를 적용한다.

1. 화면 명칭을 `메일 링크 클릭률`로 변경한다.
2. 명칭을 유지해야 한다면 값을 계산하지 않고 `GA 원천 미연결`로 표시한다.

메일 링크 클릭만으로 `클릭율(GA)`라고 단정하지 않는다.

## 전체 집계

- 회원 수는 최종 조회 범위에서 다시 고유 집계한다.
- 건수는 승인된 전체 업무키로 고유 집계한다.
- 전체 클릭률은 전체 클릭 분자 ÷ 전체 승인 분모다.
- 발송제목은 표시값이며 JOIN 키나 중복 제거 키로 사용하지 않는다.
