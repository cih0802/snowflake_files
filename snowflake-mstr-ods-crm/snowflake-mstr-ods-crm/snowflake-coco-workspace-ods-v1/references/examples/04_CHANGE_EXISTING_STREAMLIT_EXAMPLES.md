# 기존 Streamlit 변경 요청 예시

## UI만 변경

```text
$mstr-ods-crm-schema

현재 열려 있는 Streamlit의 데이터 계산은 그대로 유지하고 화면만 변경해주세요.

- 조회조건 영역을 한 줄로 정리
- 조회 버튼과 초기화 버튼 추가
- 수치에 천 단위 구분기호 적용
- 비율은 소수점 한 자리로 표시
- 표 열 순서는 그대로 유지
- 다운로드 결과와 화면 값은 같아야 함

기존 View, SQL, 지표 계산, 중복 제거 기준은 변경하지 마세요.
변경 전에 UI 파일과 데이터 계산 파일의 영향 범위를 구분해서 알려주세요.
```

## 필터 추가

```text
$mstr-ods-crm-schema

현재 Streamlit에 발송구분 대·중·소 필터와 발송제목 검색을 추가해주세요.
대분류를 선택하면 중분류가 좁혀지고, 중분류를 선택하면 소분류가 좁혀져야 합니다.

필터 추가로 기존 총계 계산이 달라지지 않도록 하고, KPI·표·다운로드에 같은 조건이 적용되는지 검증해주세요.
기존 지표 SQL은 필터 적용에 필요한 최소 범위만 변경해주세요.
```

## 지표 정의 변경

```text
$mstr-ods-crm-schema

현재 화면의 `발송 성공 수` 정의를 변경하고 싶습니다.
앞으로는 발송 요청 성공이 아니라 수신자별 최종 전송 성공만 인정합니다.

바로 수정하지 말고 다음을 먼저 알려주세요.
1. 현재 성공 수의 계산 방식
2. 새 정의로 영향을 받는 KPI·표·차트·다운로드
3. 재시도와 중복 성공을 어떻게 처리해야 하는지
4. 대표 기간에서 기존 값과 새 값의 차이

제가 변경 범위를 확인한 뒤 구현해주세요.
```
