# N07-05 · 인수인계 · 정식 산출물 문서 규약

> doc_id: N07 · as_of: 2026-10-20 · 원본 = GN_DW `85_실제 인수인계 문서/00_작업계획서.md` §1 · `95_정식산출물_생성_프롬프트.md`

## 1. 형식

- 허용 형식 = `md · sql · csv · xlsx · html`. 설명은 md 에 모으고, 나머지 형식에는 첫 줄 각주(목적 · 짝 md · 미실행 여부)만 둔다.
- 짝 파일 = `<ID>_<이름>.md` + `<ID>_<이름>.sql|csv|xlsx`. 근거 쿼리 = `_근거쿼리/<ID>_근거.sql`.
- md 헤더(YAML): `doc_id · title · version · as_of · source_docs · source_queries · owner · status(draft/review/final)`.
- 한 줄 2000자 이하(읽기 도구가 줄 단위로 자른다).

## 2. 진실의 원천

1. 라이브 메타데이터(SHOW · DESCRIBE · INFORMATION_SCHEMA · ACCOUNT_USAGE)
2. 정본 파일(DDL · dbt · SV · Agent spec)
3. 그 밖의 문서

- 문서와 라이브가 다르면 라이브를 쓰고 차이는 `_드리프트/드리프트_통합.md` 에 남긴다(유형 · 축 · 처리 · 운영계 열).
- 모든 수치는 조회 결과로 채운다. 못 잰 값은 `TBD(미검증)`. 추정치를 사실처럼 쓰지 않는다.

## 3. `[공통]` / `[ENV]` 분리 — 개발계에서 쓰고 운영계로 옮긴다

| 구분 | 무엇 | 운영계에서 |
|---|---|---|
| `[공통]` | DB 객체 구조 · 정본 파일에서 나오는 값(스키마 · SV · Agent · dbt) | 재확인만 |
| `[ENV]` | 계정마다 다른 값(사용자 · 롤 할당 · WH · 모니터 · 예산 · Task · Alert · 정책 · 태그 · 계정 파라미터 · 비용) | 근거 SQL 을 다시 돌려 채운다 |

- `[ENV]` 근거 SQL 은 `-- Q01` 처럼 문장 마커를 붙이고, 캡처 도구로 `_ENV/<계정>/<ID>_<Qnn>_<k>.csv` 에 저장한다. 그 csv 가 `[ENV]` 값의 정본이다.
- md 의 `[ENV]` 표는 계정 열(`개발계` · `운영계`)로 쓴다. 운영계 열은 캡처 전까지 `TBD(미검증)`.

## 4. 변경 SQL

- 산출물을 만드는 동안 DDL/DML/GRANT 를 실행하지 않는다. 정책·권한 변경은 `<ID>_<이름>_미실행.sql` 로만 만든다.
- 미실행 SQL 머리에: 실행 롤 · 선행 권한 · 「붙이는 순간 무엇이 바뀌나」 · 확인 SELECT · 롤백.
- 🔴 옵션 구문(한도 · 차단 · 예시 사용자)은 **반드시 주석**으로 둔다. 「현재 미적용」이라고 적어 놓고 실행 구문으로 남기면 파일 전체 실행 때 켜진다.
- 개인정보 점검은 분류기 결과 + 컬럼 COMMENT + 값 형태 집계(값은 출력하지 않는다)를 함께 본다.

## 6. 단계 종료 점검

- 근거 없는 숫자 0(`TBD` 제외) · 미실행 SQL 표기 · 드리프트 절(없으면 「없음」) · 이슈 원장 등재.
- 「게이트 전부 통과」는 규약 준수의 증거가 아니다 — 같은 값을 다르게 재는 곳 · 결정을 인용한 문서 전수 · 문서에 박힌 개수를 따로 본다.
