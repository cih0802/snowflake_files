# Semantic View 및 DW 코멘트 표준화·압축 작업계획서

---

## 1. 추진 배경 및 실측 현황

### 1) 추진 배경
- DW 물리 계층(Silver, Gold)과 서비스 계층(Semantic View, Agent)의 COMMENT는 분석가뿐만 아니라 **Cortex Analyst 및 Cortex Agent(LLM)**가 자연어 질의를 해석하고 올바른 SQL을 생성하는 데 핵심적인 메타데이터로 소비됨.
- 현행 코멘트는 과거 이슈 해결 경위, 주의사항, 집계 규칙 등이 혼재되어 일부 테이블/SV에서 장문 서술형으로 작성되어 가독성과 토큰 효율 개선이 요구됨.
- 단순 내용 삭제는 Agent의 원천 계보 질의 오답 및 잘못된 조인(cross-fact)을 유발하므로, **정보 손실 없는 구조적 표준 템플릿화(4블록 체계)**를 추진함.

### 2) 실측 현황 (`scripts/comment_len_probe.py` 기준)
- **컬럼 COMMENT (Gold 690건)**: 중위값 18자, 75% 백분위수 29자, 90% 백분위수 37자 (100자 초과 6건, 0.9%). ➔ 이미 고도로 압축되어 있어 현행 유지 원칙.
- **테이블 COMMENT (Gold 37건)**: 중위값 93자, 최대 957자 (`DIM_MEMBER_ACQUISITION`).
- **Semantic View COMMENT (17종)**: 200~400자 수준.

## 2. 4블록 표준 코멘트 템플릿 규약 (`DEC-52`)

### 1) 테이블 COMMENT 표준 템플릿 (최대 150자 권장)
```sql
COMMENT = '[엔티티 정의]. [Grain: 키1 × 키2 (1행)]. [주의: 조인/집계 제약]. [원천: 원천시스템 → BRONZE스키마명.테이블명 → SILVER.테이블명]';
```
- **작성 원칙**:
  1. 서사적 경위(과거 회의 내용, 이슈 번호 등) 배제.
  2. 반드시 포함할 4요소: ① 엔티티 정의 ② Grain ③ 조인/집계 주의사항 ④ 원천 계보.

### 2) Semantic View COMMENT 표준 템플릿 (최대 200자 권장)
```sql
COMMENT = '[SV 목적 (base: GOLD.테이블)]. [Grain: ...]. [활성 지표: ...]. [주의: Cross-fact/비가산 경고]. [원천: ...]';
```
- **작성 원칙**:
  1. Agent의 자연어 질의 지원을 위한 `[원천]`, `[주의]` 태그 명시 보존.
  2. 규칙7 준수: 코멘트 내에 고정된 행수·실측 수치 기입 금지.

## 3. 타 객체 및 스크립트 영향도 분석

| 대상 스크립트 / 컴포넌트 | 역할 및 연관성 | 작업 시 준수 사항 |
|---|---|---|
| `scripts/audit_ddl_rule7.py` / `sv_rule7_scan.py` | 규칙7(실측 수치 혼입 금지) 검사 | 코멘트에 행수, 건수, 금액 등 수치 기입 금지 |
| `scripts/comment_drift_gate.py` | DDL ↔ Snowflake Live 코멘트 일치 검사 | DDL 수정 후 반드시 Live COMMENT ON/CREATE DDL 실행 |
| `scripts/sv_unit_gate.py` | 단위(만원, 원, %, 명 등) 정합성 검사 | 표준 템플릿 내 단위 표기 보존 |
| `scripts/agent_tool_claim_gate.py` | Agent 도구 설명 ↔ SV 코멘트 정합 검사 | 도구 설명과 SV 코멘트 주장 일치 유지 |
| `scripts/gen_column_inventory_*.py` / `gen_column_mapping.py` | 산출물 카탈로그 자동 생성기 | DDL 반영 후 제너레이터 재실행하여 산출물 최신화 |
| `cortex_project/agents/*/agent_spec.yaml` | 에이전트 시스템 프롬프트 | SV COMMENT의 `[원천]` 태그 유지로 프롬프트 무수정 보장 |

1. `04_silver_design/08_SILVER_테이블DDL_20260714.sql` 코멘트 정비.
2. `03_top-down_gold/06_DDL.sql` 테이블 코멘트 37종 정비.

### **Step 2. Snowflake Live 객체 반영**
1. Gold/Silver 테이블: `COMMENT ON TABLE ...` 일괄 실행 스크립트 생성 및 적용.

3. `comment_drift_gate.py` 실행하여 DDL ↔ Live Drift 0 확인.

1. 카탈로그 재생성: `gen_column_inventory_20260811.py`, `gen_column_mapping.py`, `gen_gold_erd.py` 실행.
2. 품질 게이트 검증: `audit_ddl_rule7.py`, `sv_rule7_scan.py`, `sv_unit_gate.py`, `test_*.py` 31종 전건 PASS 확인.
3. 에이전트 스모크: 자연어 질의(원천 확인 등) 회귀 검증.
